Правило 7 [`REFACTOR_PLAN.md`](../../../docs/REFACTOR_PLAN.md): живой эталон, снят до начала правок движка

не сравниваются: шрифт проекта (`Inter Display`) системный, а не из `assets/fonts/`, и кадры зависят от машины.

Снято на машине из [`BENCH.md`](../../../docs/history/BENCH.md) (Windows 11, Pillow 11.3.0) с `build/timeline.json`
готового ролика (голос ElevenLabs, 6:59). Сценарий с этим timeline сверен: тексты и параметры всех 46 сцен совпадают.

Как снять заново — на копии, чтобы не трогать `qa/` проекта:
```
python -m studio stills <копия fake-discounts> --chapter ch01   # … ch04
```
Копия: проект без `build/` + `build/timeline.json` из боевой копии (синтеза нет, `stills` голос не трогает).
Лист: начало сцены, середина каждого бита, конец сцены; подпись — `глава/сцена t=` от начала ролика.
