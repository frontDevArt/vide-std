# Notes From The Mind — позиционирование и радар тем

> С 2026-10-23 (ROADMAP A1) канал — студия `studios/notes-from-the-mind/`: пути `channel/`, `briefs/`, `research/` ниже — от неё; `scripts/` и `.claude/` — в корне репозитория.

Комплект для вашего проекта видеостудии в Claude CLI. Он отвечает на вопрос, **о чём снимать на этой неделе**, и не даёт каналу уйти из ниши.

## Что внутри
```
channel/POSITIONING.md          ← главный документ: линза, территория, стоп-лист, фильтр, рубрики, микс, календарь, названия
channel/topics-log.md           ← журнал тем, чтобы не повторяться (уже заполнен мифами из ролика «80 фактов»)
.claude/commands/topic-radar.md ← /topic-radar: 10 тем на неделю с источниками, вердиктом, названиями и оценкой
.claude/commands/topic-to-brief.md ← /topic-to-brief N: тема № N → готовый бриф по briefs/_TEMPLATE.md
scripts/weekly-radar.sh         ← запуск радара без вас (для автозапуска по расписанию)
```

## Установлено (2026-10-21)
Комплект встроен в студию: `channel/`, `scripts/`, команды `/topic-radar` и `/topic-to-brief` в `.claude/commands/`.
Имя канала — **Notes From The Mind**. Стиль — пресет `lab` (`channel/STYLE.md` → код в `studio/`). Отчёт об интеграции — `docs/channel-kit-integration.md`.

## Еженедельный цикл
| Шаг | Команда | Результат |
|---|---|---|
| 1. Темы | `/topic-radar` (или `/topic-radar money`, `/topic-radar calendar`) | `research/radar/2026-W43.md` — 10 тем + тема недели |
| 2. Выбор | откройте отчёт, выберите номер | — |
| 3. Бриф | `/topic-to-brief 3` | `briefs/<имя>.md` на английском, с источниками |
| 4. Ролик | `/new-video briefs/<имя>.md` | готовый MP4 |
| 5. Отметка | в `channel/topics-log.md` смените статус на `published` (или `rejected`, если тема не нужна) | радар больше её не предложит |

## Автозапуск раз в неделю
Радар можно запускать на вашем компьютере каждый понедельник в 09:00, чтобы к началу недели отчёт уже лежал в проекте.

**macOS / Linux (cron):** выполните `crontab -e` и добавьте строку (замените путь на свой):
```
0 9 * * 1  /ПОЛНЫЙ/ПУТЬ/К/ПРОЕКТУ/scripts/weekly-radar.sh
```
Компьютер в это время должен быть включён. Если команда `claude` в cron не находится, укажите полный путь к ней (узнать его можно командой `which claude`) прямо в скрипте.

**Windows (ваш вариант):** `scripts/weekly-radar.ps1` вызывает `scripts/weekly-radar.sh` через Git Bash. Команды регистрации задачи в Планировщике (понедельник 09:00) — в шапке `.ps1`. Путь к `claude` скрипт ищет сам (`/c/nvm4w/nodejs/claude`), иначе задайте `CLAUDE_BIN`.

Проверить вручную до настройки расписания: `bash scripts/weekly-radar.sh` (лог — `logs/radar-<дата>.log`).

## Как настраивать
- **Сместить нишу** (добавить территорию, убрать рубрику) — правьте только `POSITIONING.md`. Команды подхватят изменения сами.
- **Тема не понравилась** — статус `rejected` в журнале, и она больше не появится.
- **Нужен фокус недели** — `/topic-radar sleep`: минимум 4 темы из 10 будут про сон, микс сохранится.
