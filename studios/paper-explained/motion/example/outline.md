# Демо моушн-приёмов — «первые слова на Луне»

Не ролик для публикации: полигон для приёмов из `research/reference-timurka-fable-motion/README.md` в вертикали 9:16.
Голос — `fake` (тон вместо речи), музыки нет, всё нарисовано кодом — бесплатно. Вид «Лунная ночь» — заглушка: смотреть
на движение, а не на оформление.

## Что где показано
| Сцена | Приём из разбора | Как сделано |
|---|---|---|
| m01 | **Предмет-герой** (п. 1) | Луна на canvas с первого кадра; в конце сцены раскрывается на весь кадр — мы «на Луне» |
| m01, m02, m03 | **Пилюли на ножке** (п. 4) | `.tag` — узел, ножка, пилюля; появляется на слове (`data-at`) |
| m02 | **Оригинал + перевод с общим маркером** (п. 2) | `.mk` — у пары фраз одно `data-at`, маркер идёт в обеих за 0,28 с; в вертикали стопкой |
| m02 | **Пунктир-связь** (п. 4) | SVG-пунктир под маской `.draw` — от карточки к переводу |
| m03 | **Один → множество со счётчиком** (п. 3) | canvas: один телевизор → поле → точки; `data-count` докручивает число по экспоненте |
| m03 | **Счётчики столбиком** (п. 4) | две пилюли `.tally` одна под другой |
| m02→m03, m03→m04 | **Нырок в картинку** (п. 6) | экран телевизора показывает тот же кадр, что фон соседних сцен: отъезд из него и нырок в него без склейки |
| m04 | **Призыв действием** (п. 5) | `.tap` нажимает сердце (заливается) и кнопку («Подписаться» → «Вы подписаны») |

Не вошли: сцена-аналогия на арте Kie (платно), частицы, шлейф-эхо, лупа.

## Код
Приёмы вынесены в общий набор студии `studios/paper-explained/motion/` (`motion.css`, `motion.js`, шпаргалка
`README.md`) — пользователь одобрил демо 2026-11-16 («класс… мне нравится»; озвучивать не надо). Здесь, в
`assets/src/`, остались: `common.css`, `live.css`, `common.js` — копия из `voyager-love`; `moon.css` — только вид
«Лунная ночь»; `moon.js` — мир на canvas (Луна, поверхность, телевизоры) через `window.motion.onFrame`; `build.py` —
образец подключения набора. После переноса кадры сверены с прежними: расхождение не больше 2 единиц из 255.
