# Набор моушн-приёмов «На бумаге»

**Одобрено пользователем 2026-11-16** («класс… мне нравится») на демо `projects/motion-moon-demo/`. Это общий код
приёмов студии: его подключает любой новый ролик, в каком бы визуальном мире он ни был. Набор задаёт движение и форму
приёма, вид (цвета, шрифты, фактура) — у каждого ролика свой.

- `motion.css` — приёмы (пилюля на ножке, общий маркер, счётчики, призыв действием, вход из глубины).
- `motion.js` — счётчик `data-count` и `window.motion` (время слов, точки сцены → кадр, свой рисунок на каждый кадр).
- Откуда приёмы и замеры движения — `research/reference-timurka-fable-motion/README.md`.
- `example/` — исходники демо со всеми приёмами: четыре сцены (`m01`–`m04.body.html`), мир ролика (`moon.css`,
  `moon.js`), `build.py`, сценарий. Собранное демо — `projects/motion-moon-demo/` (в git не идёт: папки `*-demo`
  в `.gitignore`), поэтому образец лежит здесь; как собрать демо заново — в конце файла.

## Как подключить в новом ролике
В `assets/src/build.py` проекта (образец — `example/build.py`):
```python
KIT = OUT.parents[2] / "motion"   # studios/paper-explained/motion
css = common.css + live.css + KIT/"motion.css" + <мир ролика>.css      # мир — последним: перекрывает цвета набора
js  = common.js  + KIT/"motion.js"  + <мир ролика>.js                  # каждый в своём <script>, в этом порядке
```
Цвета набора мир ролика меняет переменными в `:root`: `--m-text`, `--m-accent`, `--m-mark`, `--m-ring`, `--m-pill`,
`--m-line`, `--m-card`, `--m-card-ink`, `--m-like`, `--m-ok`, `--m-badge` (фон значка на карточке оригинала).
Время появления у всего — `data-at="слово[:сдвиг]"` (слово озвучки, как везде в студии).

## Приёмы

### 1. Предмет-герой
Символ темы виден с первого кадра и присутствует в каждой сцене; сцены раскрываются из него и сворачиваются в него.
В демо это Луна: диск → раскрытие на весь кадр → экран телевизора → фон призыва. Кода в наборе нет — это решение
сценария: выбрать предмет до раскадровки и записать в `outline.md`, где он в каждой сцене.

### 2. Оригинал + перевод с общим маркером
Когда источник — чужой текст (пост, цитата, документ) и важно показать, что он настоящий. В вертикали — стопкой:
карточка оригинала сверху (небольшая, как улика), перевод крупно снизу. У пары фраз одно `data-at` — маркер идёт в
обеих сразу. Подписи сверху в такой сцене выключить: `<div class="stage nocaps">` — их роль играет перевод.
```html
<div class="orig zup" style="left: 6px; top: -170px; width: 708px; --d: .05s">
  <div class="hd"><i></i>Apollo 11 · запись NASA · 21.07.1969</div>
  <div class="tx">That's <span class="mk" data-at="маленький:-0.05">one small step</span> …</div>
</div>
<div class="glass2" style="left: 0; top: 172px; width: 716px; height: 770px"></div>
<div class="lab" style="left: 26px; top: 152px">перевод</div>
<div class="ru" style="left: 30px; top: 228px"><span class="mk" data-at="маленький:-0.05" data-sfx="marker">Маленький шаг</span> …</div>
```
Маркер — 0,28 с на фразу (`--dd`). Правило 8 канала («чужое — перерисовать по-русски») остаётся для случаев, когда
сам источник не важен; этот приём — когда важен.

### 3. Пилюля на ножке
Объяснить термин или подписать предмет прямо в кадре (правило «понятно новичку»). Узел встаёт на предмет, ножка
растёт, пилюля выскакивает. `.tag` — пилюля под узлом, `.tag.over` — над узлом.
```html
<div class="tag" style="left: 298px; top: 412px; --st: 42px; --fs: 48px" data-at="человека:0.2"><i></i><b>один астронавт</b></div>
<div class="tag over" style="left: 96px; top: 128px; --st: 80px; --sx: 52px" data-at="июле:-0.1"><i></i><b>июль 1969</b></div>
```
`--st` — длина ножки, `--sx` — где ножка под пилюлей (сдвинуть пилюлю влево: увеличить `--sx` и уменьшить `left`),
`--fs` — кегль. Узел у `.tag` — в точке `(left + sx + 1, top)`. Убрать пилюлю — обернуть в `<div class="abs out" data-at="…">`.

### 4. Кольцо на слове и пунктир-связь
```html
<span class="rw">man<svg viewBox="0 0 100 50" preserveAspectRatio="none"><ellipse class="draw" cx="50" cy="25" rx="49" ry="24"
      pathLength="1" style="--dd: .3s; --d: 99s" data-at="человека:0.2" data-sfx="none"/></svg></span>

<div class="node" style="left: 60px; top: 62px; --d: .45s"></div>
<svg class="ink" width="720" height="1100" viewBox="0 0 720 1100">
  <defs><mask id="cm" maskUnits="userSpaceOnUse" x="0" y="0" width="720" height="1100">
    <path class="draw" d="M60 66 V 150" pathLength="1" stroke="#fff" stroke-width="22" style="--dd: .25s; --d: .5s" data-sfx="none"/></mask></defs>
  <path class="dotted" d="M60 66 V 150" mask="url(#cm)"/>
</svg>
```
У маски обязательно `maskUnits="userSpaceOnUse"` с размерами: у прямой линии рамка нулевой ширины, и без этого
пунктир не виден.

### 5. Счётчик, «один → множество», счётчики столбиком
Вместо просто огромной цифры: одна вещь отъезжает и оказывается одной из тысяч, число докручивается.
```html
<div class="plate zin" style="left: 2px; top: 60px; width: 714px; --d: 99s" data-at="шестьсот:-0.25">
  <div class="count" data-count='{"to": 650000000, "at": "шестьсот:-0.1", "dd": 1.35}'>1</div>
  <small>человек у телевизоров</small>
</div>
<div class="tally" style="left: 14px; top: 890px; --d: 99s" data-at="миллионов:0.3" data-sfx="pop">по оценке NASA</div>
<div class="tally" style="left: 14px; top: 978px; --d: 99s" data-at="человек:0.15" data-sfx="pop">каждый пятый на Земле</div>
```
Счётчик растёт по экспоненте (цифры мелькают), `dd` — за сколько секунд, `from` — с чего (по умолчанию 1).
Само поле «множества» рисует мир ролика на canvas — образец `drawTv` в `example/moon.js`: камера с четырьмя
состояниями (во весь экран → герой → много → точки), упрощение рисунка по мере отъезда, герой в кольце маркера.

### 6. Нырок в картинку (стык без склейки)
Последний предмет сцены — экран, рамка, окно — показывает ровно тот кадр, с которого начинается следующая сцена.
Камера влетает в него, и склейки не видно. Держится на одной общей картинке в соседних сценах: в демо «лунный кадр»
— текстура с одним центром и масштабом — это и раскрывшаяся Луна, и фон сцены с переводом, и экран телевизора.
Наезд ускоряется (в логарифме масштаба), 0,6 с; вёрстка поверх в это время гаснет (`.dive2` из `live.css`).
Перед отъездом наружу вёрстку убрать вглубь: обёртка `<div class="outz">`. Вход после влёта — `.zup` (из глубины).

### 7. Призыв действием
Кнопки нажимаются сами и меняют состояние — зритель видит действие, а не просьбу.
```html
<svg class="heart2 zin" style="left: 190px; top: 340px; width: 340px; height: 312px; --d: .35s" viewBox="0 0 120 110">
  <path class="ol" d="…сердце…"/><path class="fl" d="…то же…" style="--d: 99s" data-at="лайк:0" data-sfx="pop"/>
  <circle class="bu" cx="60" cy="52" r="60" style="--d: 99s" data-at="лайк:0"/>
</svg>
<div class="tap" style="left: 360px; top: 500px; --d: 99s" data-at="лайк:-0.42"></div>
<div class="subw rise2" style="left: 40px; top: 770px; width: 640px; --d: .5s">
  <div class="sub a" style="--d: 99s" data-at="подпишитесь:0.2">Подписаться</div>
  <div class="sub b" style="--d: 99s" data-at="подпишитесь:0.2" data-sfx="tick"><svg viewBox="0 0 54 54"><path d="M8 28 L22 42 L46 12"/></svg>Вы подписаны</div>
</div>
<div class="tap" style="left: 360px; top: 846px; --d: 99s" data-at="подпишитесь:-0.22"></div>
```
Касание `.tap` нажимает на 0,42 с от своего старта — поэтому сдвиг `-0.42` ставит нажатие ровно на слово.
Путь сердца целиком — `example/m04.body.html`.

## Свой рисунок на canvas (`window.motion`)
```js
const M = window.motion;                       // после motion.js
const { W, H, D, fx, fy, when, cl, lerp, eo, eio, rng, hash } = M;
M.onFrame((t) => { /* нарисовать кадр сцены в момент t — чистая функция t */ });
```
`fx(x)`, `fy(y)` — точка сцены (px внутри `.scene`) → точка кадра: так пометка в вёрстке попадает на предмет с
canvas. `when("слово:-0.1")` — время слова. Холст — `<canvas class="world" data-backdrop>` во весь кадр
(`data-backdrop` — проверка безопасной зоны его не считает). Если пометки привязаны к предмету на canvas, сцене
ставить `style="--ps: 1"`: иначе её медленный наезд уводит пометки с предмета.

## Тайминги (замеры по референсу)
Раскрытие/сворачивание 0,25–0,7 с · перелёт камеры 0,3 с · кольцо 0,3 с · фраза маркером 0,2–0,3 с · пилюля
0,1–0,25 с · нырок 0,6–0,9 с · счётчик 0,4–1,4 с · в покое — медленный наезд 1–2 % в секунду. Крупная смена кадра
каждые 2–2,5 с, между сменами что-то всегда движется.

## Ловушки
- **Имена классов.** Перед новым именем — поиск по `common.css`: там уже есть `.up` (сдвиг на 250 px вверх), `.out`,
  `.draw`, `.pop`, `.appear`… Имена набора перечислены в шапке `motion.css`.
- **Безопасная зона.** Вход `.zin` стартует с масштаба 1,8 — элемент во всю ширину на кадре 0,12 с вылезает за край;
  для таких — `.zup`. Всё важное — левее x 720 в сцене.
- **Высота кадра.** Раскладку тянуть до y ≈ 1000–1100 сцены: в демо сцены 2 и 4 кончаются на 2/3 высоты — низ пустой.
- **Последняя пометка сцены** должна успеть прочитаться до нырка: `hold:` у сцены в сценарии (в демо 0,9–1,2 с).
- **Canvas дорог в рендере:** ~0,8 кадра/с на процесс (24 с демо — около 15 минут). Рендер — в фоне.
