# START HERE — передача проекта на локальный Claude CLI

Это всё, что было сделано в облачной сессии 20 октября 2026: студия-MVP, документация, демо,
исходные логи первого прогона, разбор гайда Claude Motion и план дальнейшей работы.

## 1. Что это
Студия превращает **тему** в **готовый MP4**: сценарий по главам → озвучка (язык — `language`, ru по умолчанию) → анимация,
нарисованная кодом → субтитры → музыка → автопроверка. Короткие ролики — за одну сессию,
длинные (до часа) — по главам, по одной главе за сессию.

## 2. Запуск у себя (5 шагов)
```bash
unzip video-studio.zip && cd video-studio
pip install -r requirements.txt                 # numpy, Pillow, PyYAML; нужен ffmpeg в системе
python -m studio doctor                          # что работает на этой машине
pip install edge-tts   # ЛИБО (лучший голос, нужен интернет) — затем tts.backend: edge
bash tools/setup_rhvoice.sh  # ЛИБО офлайн-голос (Linux/macOS, ~3 мин на 2 ядрах, один раз)
claude                                           # открыть Claude Code в этой папке
```
Подробно по ОС — `docs/LOCAL_SETUP.md`.

Первая проверка, что всё живо (соберёт демо стиля 10–15 с из заготовки и прогонит QA):
```bash
python -m studio new regress --lang en
# без RHVoice (Windows): в projects/regress/project.yaml → tts.backend: edge
python -m studio demo regress      # потом удалить projects/regress*
```

## 3. Команды в Claude CLI
| Команда | Что делает |
|---|---|
| `/new-video <тема, длительность, формат>` | новый ролик: бриф → план → (короткий) сразу MP4 |
| `/next` | продолжить: следующая фаза или глава |
| `/chapter <slug> chNN <что изменить>` | написать/переписать одну главу |
| `/qa` | собрать, проверить, отдать |
| `/roadmap` | взять следующую задачу: сначала `docs/REFACTOR_PLAN.md`, потом `docs/ROADMAP.md` |
