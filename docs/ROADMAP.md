## Видение
Сейчас студия — это один канал (Notes From The Mind), один формат («диктор + анимация + субтитры») и один выход
(MP4 под YouTube). Цель — **производство видео для любого количества клиентов**:

```
Студия (workspace)   = YouTube-канал, бренд или клиент. Свой бренд-кит, голос, языки, площадки, правила, секреты, календарь.
 └─ Проект           = ролик или серия роликов. Тип ролика: объяснялка, промо, ролик под музыку, слайдшоу, туториал…
     └─ Выходы       = YouTube 16:9 · Shorts / TikTok / Reels 9:16 · лента 4:5 и 1:1 · реклама 6/15/30 с
                       + пакет к выходу: субтитры, обложка, описание, хэштеги, источники, главы
```

Три типовых студии, под которые всё проектируется:

| Студия | Цикл | Что важно |
|---|---|---|
| **YouTube-канал** (как Notes From The Mind) | радар тем → бриф → длинный ролик → нарезка Shorts → публикация → аналитика | факты с источниками, единый стиль, главы, длинные ролики |
| **Бренд в TikTok / Instagram** | контент-план → серия коротких роликов → публикация по расписанию | бренд-кит, фото продукта, логотип, музыка и тренды, ролики без голоса, безопасные зоны площадок |
| **Разовый заказ клиента** | бриф клиента → ролик → ревью клиента → правки → сдача пакета | быстрые черновики, правки по таймкодам, версии, пакет файлов под все площадки |

Принципы остаются: всё нарисовано кодом или собрано из ассетов с известной лицензией, состояние в файлах,
сначала дешёвый просмотр, потом дорогой рендер. Платное (голос, генерация картинок) — только после оценки
стоимости и «да» пользователя.

**Готово, если:** серия из 5 коротких роликов бренда рендерится одной командой без присмотра, утром у всех QA ✅.

**Готово, если:** ролик канала собирается на 2-м языке, QA ✅, на листах нет непереведённого текста.

### [ ] D4. Ворота качества

**Готово, если:** нарушения из брифа ловятся с понятным сообщением, правила студии берутся из `studio.yaml`.

### [ ] D5. Версии и сдача

пакета для клиента.
**Готово, если:** две версии ролика лежат рядом, видно, чем они отличаются.
