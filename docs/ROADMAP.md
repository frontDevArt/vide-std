# Roadmap v2: студия, которая делает любое видео для любого клиента

Заменяет старый roadmap (2026-10-20, архив: [`history/ROADMAP_v1.md`](history/ROADMAP_v1.md)). Основа — [`AUDIT.md`](AUDIT.md).
Порядок работ: сначала [`REFACTOR_PLAN.md`](REFACTOR_PLAN.md) (этапы 0–2 обязательны), потом этот документ.
`/roadmap` берёт первую неотмеченную задачу. Отмечайте `[x]` и коротко пишите, как проверено.

## Видение
Сейчас студия — это один канал (Notes From The Mind), один формат («диктор + анимация + субтитры») и один выход
(MP4 под YouTube). Цель — **производство видео для любого количества клиентов**:

```
Студия (workspace)   = YouTube-канал, бренд или клиент. Свой бренд-кит, голос, языки, площадки, правила, секреты, календарь.
 └─ Проект           = ролик или серия роликов. Тип ролика: объяснялка, промо, ролик под музыку, слайдшоу, туториал…
     └─ Выходы       = YouTube 16:9 · Shorts / TikTok / Reels 9:16 · лента 4:5 и 1:1 · реклама 6/15/30 с
                       + пакет к выходу: субтитры, обложка, описание, хэштеги, источники, главы
```

Три типовых студии, под которые всё проектируется:

| Студия | Цикл | Что важно |
|---|---|---|
| **YouTube-канал** (как Notes From The Mind) | радар тем → бриф → длинный ролик → нарезка Shorts → публикация → аналитика | факты с источниками, единый стиль, главы, длинные ролики |
| **Бренд в TikTok / Instagram** | контент-план → серия коротких роликов → публикация по расписанию | бренд-кит, фото продукта, логотип, музыка и тренды, ролики без голоса, безопасные зоны площадок |
| **Разовый заказ клиента** | бриф клиента → ролик → ревью клиента → правки → сдача пакета | быстрые черновики, правки по таймкодам, версии, пакет файлов под все площадки |

Принципы остаются: всё нарисовано кодом или собрано из ассетов с известной лицензией, состояние в файлах,
сначала дешёвый просмотр, потом дорогой рендер. Платное (голос, генерация картинок) — только после оценки
стоимости и «да» пользователя.

## Этап A — Мультистудия

### [ ] A1. Студии как папки (`studios/<id>/`)
**Зачем.** Сейчас канал размазан по корню (`channel/`, `briefs/`, `research/`, `projects/`), второму каналу или бренду некуда лечь.
**Сделать.**
- Структура:
  ```
  studios/<id>/
    studio.yaml        # kind: youtube | brand | client; языки; площадки; голос; стиль/бренд-кит; правила QA; CTA
    CLAUDE.md          # правила этой студии (Claude Code подхватывает вложенные CLAUDE.md)
    brand/             # бренд-кит (A2)
    channel/           # позиционирование, стиль, журнал тем (для kind: youtube)
    briefs/  research/  projects/  output/
  ```
- Резолвер (`studio/workspace.py`, REFACTOR P2.8): `python -m studio --studio <id> <команда>`, `python -m studio studios`
  (список студий и проектов), `new --studio <id>`. Студия по умолчанию — `default`, ей принадлежит старый `projects/`
  (обратная совместимость, ничего не переносится насильно).
- Перенос Notes From The Mind в `studios/notes-from-the-mind/` одним коммитом через `git mv`; правила канала из корневого
  `CLAUDE.md` переезжают в `studios/notes-from-the-mind/CLAUDE.md`, в корне остаются общие правила студии.
- `project.yaml` наследует настройки по цепочке `DEFAULTS → studio.yaml → project.yaml`.

**Готово, если:** `fake-discounts` после переноса проходит `status` и `stills` без изменений, `/topic-radar` пишет в папку
своей студии, а `python -m studio studios` показывает 2 студии.

### [ ] A2. Бренд-кит (обобщение пресета `lab`)
**Зачем.** `lab` зашит в код (`gfx.STYLES`, `lab.py`). Для каждого бренда нужен свой стиль без программирования.
**Сделать.**
- `studios/<id>/brand/brand.yaml`: палитра (роли: фон, текст, акценты, «хорошо/плохо»), шрифты по ролям (файлы
  в `brand/fonts/` + лицензия), логотип (SVG/PNG, светлый и тёмный), радиусы, толщина линий, тип фона (`lab`, градиент,
  сплошной, фото/видео-подложка), камера вкл/выкл, стиль субтитров (плашка, караоке, крупные TikTok-субтитры),
  интро/аутро (логотип-«стинг»), плашка CTA, музыка по умолчанию, тон голоса.
- Стиль строится из бренд-кита (объект `Style`, REFACTOR P2.2); `lab` становится бренд-китом студии Notes From The Mind.
- Свой стиль по референсу (решение 2026-10-20, старый R3): описание + скриншоты → Claude заполняет `brand.yaml` →
  `stills` → подтверждение.

**Готово, если:** один и тот же сценарий собирается в стилях двух студий, листы `stills` явно разные, а на `fake-discounts`
стиль `lab` из бренд-кита даёт кадры пиксель в пиксель как раньше.

### [ ] A3. Голос, языки и секреты на студию
**Сделать.** `studios/<id>/.env` (свой ключ и голос ElevenLabs у каждого клиента; корневой `.env` — запасной); в `studio.yaml` —
голоса по языкам, рабочий темп (калибровка из REFACTOR P1.9 сохраняется на студию: `voices.yaml` с измеренными слов/мин),
политика акцентов. Секреты никогда не выводятся.
**Готово, если:** две студии с разными голосами ElevenLabs собирают демо без правок `project.yaml`, кэш TTS не смешивается.

### [ ] A4. `/new-studio` — мастер новой студии
**Сделать.** Команда: тип студии, ниша/продукт, площадки, языки, голос; бренд по описанию + логотип + скриншоты сайта →
`studio.yaml`, `brand/`, `CLAUDE.md` студии; для `youtube` — позиционирование по образцу `POSITIONING.md`; в конце —
демо стиля 10–15 с на утверждение (как `studio demo`).
**Готово, если:** за одну сессию из описания тестового бренда получается студия и утверждённое демо.

## Этап B — Мультиплатформа: один проект → много выходов

### [ ] B1. Профили площадок (`studio/platforms.py`)
**Сделать.** Профиль: размер кадра, fps, предел длительности, безопасные зоны (поля + интерфейс площадки: правая колонка
и низ у TikTok/Reels/Shorts), громкость, вшитые субтитры да/нет, кодек и битрейт, обложка. Начальный набор: `youtube`,
`youtube-shorts`, `tiktok`, `instagram-reels`, `instagram-feed` (4:5), `square` (1:1), `ad-6`, `ad-15`, `ad-30`.
Актуальные пределы площадок сверять по их документации при реализации, а не по памяти.
**Готово, если:** `python -m studio platforms` печатает таблицу, а QA проверяет выход по профилю его площадки.

### [ ] B2. Адаптивная вёрстка шаблонов
**Зачем.** Вертикаль у `lab_*` сейчас сломана (AUDIT 3.2), а 9:16 — основной формат для TikTok, Reels и Shorts.
**Сделать.** Сетка безопасной зоны в контексте шаблона (`self.safe`), раскладки для 16:9 / 9:16 / 1:1 / 4:5 у каждого шаблона
(или явный отказ: `formats` в метаданных), QA «контент в безопасной зоне» становится ❌ (REFACTOR P1.10). Первым делом —
все `lab_*` в 9:16 по STYLE §12.
**Готово, если:** фикстура-галерея в 9:16 и 4:5 без предупреждений о безопасной зоне, листы проверены глазами.

### [ ] B3. Несколько выходов из одного проекта
**Сделать.** В `project.yaml`: `deliverables: [youtube, youtube-shorts, tiktok]`. Общие для всех выходов: сценарий, озвучка
и тайминг. Для каждого выхода отдельно: вёрстка, рендер и кэш (`build/<выход>/`). `render`/`assemble`/`qa` получают
`--out <выход>`, без флага собираются все. Результат — `output/<slug>/<выход>.mp4`.
**Готово, если:** `fake-discounts` собирается в 16:9 и 9:16 из одного сценария, оба QA ✅.

### [ ] B4. Нарезка: длинный ролик → короткие
**Сделать.** `python -m studio cutdown <проект> --to youtube-shorts --count 3`. Claude выбирает отрезки с крючком (главы,
вердикты, сильные цифры), при необходимости дописывает 1 строку крючка в начало и CTA в конец. Получается проект-нарезка
со ссылками на сцены исходника (озвучка переиспользуется из кэша) и вёрсткой 9:16. Предел длительности — из профиля площадки.
**Готово, если:** из `fake-discounts` получаются 3 Shorts, каждый QA ✅ и в пределах длительности площадки.

### [ ] B5. Пакет к выходу
**Сделать.** Рядом с MP4: `.srt`/`.vtt`, обложка (шаблоны обложек в бренд-ките; кадр + заголовок), `description.md` (описание,
главы YouTube из таймлайна, источники — для канала обязательно, хэштеги — для TikTok/Instagram), `checklist.md`
(что проверить перед публикацией, включая отметку «синтетический контент», где площадка её требует).
**Готово, если:** `output/<slug>/` содержит всё для ручной загрузки на каждую площадку из `deliverables`.

## Этап C — Любое видео: форматы, медиа, музыка

### [ ] C1. Типы роликов (`kind` в `project.yaml`)
