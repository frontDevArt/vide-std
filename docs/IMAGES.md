# Картинки для сцен (ROADMAP C5)

Картинку генерирует модель, анимирует наш Python (шаблон `media.image`). Включается на ролик: `images.enabled` в
`project.yaml`. Платно — только после сметы и «да» пользователя. Здесь — выбор сервиса и модели (C5.1, 2026-10-24).

## Сервис: Kie AI
Агрегатор моделей (Google, ByteDance, BFL, OpenAI, Recraft…) с одним API и одним ключом `KIE_API_KEY` (`.env`).
- Задача: `POST https://api.kie.ai/api/v1/jobs/createTask` `{model, input}` → `data.taskId`.
- Статус: `GET /api/v1/jobs/recordInfo?taskId=…` → `state`: `waiting | queuing | generating | success | fail`;
  ссылки — `resultJson.resultUrls` (строка JSON), цена — `creditsConsumed`. Задача без результата 10 мин → код 408.
- **Ошибка приходит с HTTP 200** — смотреть поле `code`; 402 — нет кредитов.
- Баланс: `GET /api/v1/chat/credit` → `data` (кредиты). Смету сверять с ним до и после.
- Свои картинки на вход (правка, раскладка на слои, референс стиля) — только URL: загрузка
  `POST https://kieai.redpandaai.co/api/file-stream-upload` (multipart) → `data.downloadUrl`; файл живёт 24 ч.
- Курс: **200 кредитов = $1**. Документация: `docs.kie.ai` (полный список — `docs.kie.ai/llms.txt`).

## Бэкенды (`studio/imagegen.py`, C5.3)
`images.backend`: `kie` — платно; `fake` — процедурные PNG из ключа, офлайн и бесплатно (тесты, selftest); `none` —
генерации нет, нужны готовые файлы. `plan(proj)` — работы ролика по порядку: `image` (генерация), `layers` (раскладка
`role: scene` с `layers:`), `cutout` (`role: subject`; `rembg` — локальный шаг команды `images`, C5.4). `estimate(proj)` —
смета того, чего ещё нет в кэше: кредиты, $, `over` при превышении `budget_usd`; модель без замеренной цены (`credits:
None` в `MODELS`) считается по 20 кредитов и попадает в `unpriced`. `generate(proj, job)` — одна работа, файл
пишется атомарно (`.part` → замена). Файлы кэша в `assets/images/`: `<ключ>.png`; раскладка — `<ключ>.layers/`
(`base.png`, `1.png`…, `layers.json` с `box` в долях кадра 0–1); вырезанный объект — `<ключ>.cut.png`.
- Кадр — по формату проекта (`vertical` → 9:16, `portrait` → 4:5…), `subject` — 1:1; нет такого у модели — ближайший.
- Картинки-входы (референс `images.reference`, база у `state_b` — первой) загружаются через `file-stream-upload`;
  модель без входов (`google/nano-banana`, `flux-3/klein`) меняется на свою `edit`-модель.
- `kie`: `createTask` → опрос `recordInfo` раз в 4 с до `success`/`fail`, таймаут 600 с. Ошибка по `code` даже при
  HTTP 200; 4xx (401 ключ, 402 кредиты, 403, 422) — сразу ошибка без ретраев; сеть и 5xx при опросе — до 3 раз подряд,
  создание задачи не повторяется (оно стоит денег). Ключ в сообщениях ошибок вырезается.

## Модели-кандидаты
Цены — по странице Kie или замеру `creditsConsumed`; «?» — не опубликовано, уточнить замером.

| Модель (`model`) | Что делает | Цена за картинку | Плюсы | Минусы |
|---|---|---|---|---|
| `google/nano-banana` | текст → картинка, ~1024 px | 4 кр = **$0.02** (замер C5.0) | дёшево, держит палитру из hex, текста нет | мало пикселей для 1080p, нет сида и референса |
| `google/nano-banana-edit` | правка по картинкам-входам (до 10) | ? (пример — 3 кр) | «та же сцена, но…» → `state_b`, `before_after` | вход — только URL (загрузка) |
| `nano-banana-2` | текст + до 10 референсов, 1K/2K/4K | 8 / 12 / 18 кр = $0.04 / **$0.06** / $0.09 (2K — замер) | 2752×1536 в 2K; референс держит стиль и даже ту же комнату | дороже в 3 раза; референс «протекает» в фон объекта |
| `flux-3/klein-text-to-image` (+ `klein-edit-image`) | текст → картинка, 1K/2K/4K, `seed` | 1.6 / 2.5 / 6.5 кр = $0.008 / **$0.0125** / $0.0325 (2K — замер) | в 5 раз дешевле, 2736×1536, палитра из hex держится, есть сид | лицензия «Klein» не проверена; без референса стиль плывёт от картинки к картинке |
| `seedream/5-flash-layer-decomposition` | картинка → базовая + слои PNG с `bounding_box` | 12.96 кр = **$0.065** за базу + 3 слоя (замер) | **база — сцена без объектов с дорисованным фоном**, слои прозрачные: готовый параллакс с одним ракурсом | слои в ~2 раза крупнее рамки — масштабировать в `bounding_box` |
| `recraft/remove-background` | вырезание фона | ? (пример — 1 кр) | без локальной модели | вход ≤ 5 МБ, выход, судя по примеру, webp |

Ещё есть Seedream 5 (Flash/Lite/Pro), Imagen 4, GPT Image 2/2.5, Ideogram V3, Qwen, Wan 2.7 — без явного
преимущества для плоской векторной иллюстрации; смотреть, если основные не подойдут.

## Вырезание объекта: локально
`rembg` + `isnet-general-use` (179 МБ, Apache-2.0) в отдельном `tools/rembg-venv/` — бесплатно, офлайн, чисто на
плоской иллюстрации (C5.0). Свой venv: в окружении студии `rembg` поднял бы Pillow (риск для golden). В venv стоит
onnxruntime 1.20.1: свежий падает при импорте на системном VC++ runtime 14.32 (нужен 14.40+). Модель качается в
`~/.rembg/models/` с релизов GitHub `danielgatis/rembg`, md5 проверяется. Не брать `bria-rmbg` — некоммерческая.
Запасной вариант — `recraft/remove-background` у Kie.

## Лицензия (монетизируемые ролики)
- **Kie AI** (Terms of Use): о правах на сгенерированное молчат — есть только «You retain ownership of your User
  Content». **Письменный ответ поддержки (2026-10-24):** картинки, сгенерированные через Kie, можно использовать
  коммерчески по условиям поставщика модели; своих ограничений сверх условий поставщика Kie не добавляет. Итого права
  на выход определяют только условия поставщика модели (Google, BFL, ByteDance…) — их и проверять.
- **Google (Nano Banana):** условия Gemini API, раздел «Use of Generated Content» — Google не претендует на
  сгенерированное; ответственность за использование — на нас. Коммерческое использование не запрещено.
- **BFL (FLUX):** у открытых весов разные лицензии ([dev] — некоммерческая); для Klein через Kie не проверено → не
  умолчание.
- **ByteDance (Seedream), Recraft:** не проверено.
- В `assets.yaml` у каждой картинки: модель, промпт, цена, лицензия — «Google Gemini API terms (через Kie AI)» и т. п.

## Сравнение на одних промптах (2026-10-24, 41.96 кр ≈ $0.21)
Проект `projects/c5-spike/` (сцены s05–s07; в `compare/` — листы `sheet-models.jpg`, `sheet-layers.jpg` и ответы Kie). Промпты одни: стиль-суффикс с hex палитры `lab` и
«Camera: side view at eye level»; у `nano-banana-2` вдобавок референс — фон из C5.0.
- **Сцена «комната + человек».** `nano-banana-2` с референсом повторил ту же комнату (окно, тумбочка, пол) — стиль
  ролика держится между картинками. `klein` без референса — своя комната (луна, другой пол), тоже в палитре и чисто.
- **Объект на сером для вырезания.** Оба — нужный ракурс сбоку. У `nano-banana-2` референс протёк в фон (тёмный градиент
  снизу) — `rembg` всё равно вырезал чисто. У `klein` фон светлее заказанного, вырезано чисто. Оба 2K — кромка гладкая
  (в C5.0 при ~480 px была ступенчатой).
- **Раскладка на слои.** Seedream по промпту «комната / кровать с человеком / тумбочка с лампой» отдал базу — **пустую
  комнату с дорисованным полом и стеной** — и три прозрачных слоя с `bounding_box`. Слой, поставленный на холст кадра по
  рамке, совпал с базой пиксель в пиксель; параллакс в шаблоне `image` без двойников и дыр. Это снимает боль C5.0 «у фона
  и объекта разный ракурс».
- Текста и букв на картинках нет ни у одной модели.

## Умолчание
```yaml
images:
  backend: kie
  model: nano-banana-2      # 2K: $0.06; первая удачная картинка ролика — референс для остальных
  resolution: 2K
  layers: seedream/5-flash-layer-decomposition   # motion: parallax — сцена целиком → база + слои (~$0.065)
  cutout: rembg             # одиночный объект «стикером» на фоне кита: rembg | kie (recraft) | none
```
Сцена с параллаксом ≈ $0.06 + $0.065 = $0.125, просто картинка — $0.06; ролик 10–20 картинок ≈ $0.6–2 при
`budget_usd: 3`. Черновики и спайки — `google/nano-banana` ($0.02). `flux-3/klein` ($0.0125) — кандидат в дешёвое
умолчание после проверки лицензии BFL на Klein и пробы `klein-edit-image` с референсом.

## Что это значит для C5.2–C5.5
- Слой параллакса из раскладки ставится по `bounding_box` (нормированный 0–1000): шаблону `image` нужен у слоя `box`
  (место и размер на кадре) — тогда не нужен промежуточный PNG на весь кадр. Тот же `box` нужен и стикеру (C5.0).
- Слой с `depth: 1.0` уезжает за край кадра при `pan` ±0.6 — у ближних слоёв ход меньше или `pan` скромнее.
- Загрузка своих картинок (референс, вход раскладки) — через `file-stream-upload`, ссылка живёт 24 ч: кэшировать
  результат, а не ссылку.
