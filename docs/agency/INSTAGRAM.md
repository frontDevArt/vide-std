# Instagram и Facebook агентства: регистрация и запуск (Армения)

Исследование 2026-10-29 (Claude, по запросу пользователя). Аккаунты заводит и публикует только человек. Реклама —
[`ADS.md`](ADS.md); TikTok — [`TIKTOK.md`](TIKTOK.md) (отложен).

## Главное
- **Порядок важен:** личный профиль Facebook → бизнес-портфолио → страница Facebook → Instagram → связка. Всё
  бизнес-хозяйство Meta висит на живом человеке: страницами управляет личный профиль, фейковые профили банят — и
  вместе с ними теряются страница и портфолио. Поэтому — **реальный профиль пользователя** + второй администратор.
- **Тип Instagram — «Бизнес»**, не «Автор»: агентство, реклама, кнопки контакта, API для статистики и радара
  (Business Discovery требует IG Business, привязанный к странице Facebook — [`RADAR.md`](RADAR.md)). Минус —
  урезанная музыкальная библиотека; нам не мешает: музыку делает студия.
- Без VPN, одно устройство, армянский интернет: смена мест и VPN — частая причина блокировок новых аккаунтов
  (по отраслевым гайдам, официальных лимитов Meta нет).
- Meta Verified для бизнеса в Армении — **не подтверждено**; сейчас не нужно.

## Регистрация (шаги)
1. **Личный профиль Facebook** пользователя (свой, реальный; если нет — завести на личную почту, не на
   `yereva.am@gmail.com`). Двухфакторная защита.
2. **Бизнес-портфолио** — business.facebook.com → создать: название «Yereva», почта `yereva.am@gmail.com`.
   Сразу добавить второго администратора — доверенного человека со своим реальным профилем (второй свой профиль
   нарушает правила Meta); без него потеря одного профиля = потеря всего.
3. **Страница Facebook** «Yereva» внутри портфолио: категория «Маркетинговое агентство», сайт `yereva.am`,
   город Ереван (адрес не указывать, пока нет офиса), аватар `studios/yereva/brand/logo/out/avatar-1080.png`.
4. **Instagram** — с телефона на армянской SIM: регистрация на `yereva.am@gmail.com`, ник `@yereva.am`,
   имя «Yereva · SMM Ереван». Двухфакторная защита.
5. Настройки → Тип аккаунта → **Профессиональный → Бизнес**, категория «Маркетинговое агентство».
6. **Связать:** Instagram ↔ страница Facebook (Центр аккаунтов) и Instagram → бизнес-портфолио
   (business.facebook.com → Настройки → Аккаунты Instagram).
7. Кнопка контакта — **WhatsApp Business** (отдельный номер агентства, [`CASE.md`](CASE.md) §3) и почта.
8. **Рекламный аккаунт** в портфолио — только когда дойдём до рекламы. **Валюту и часовой пояс выбрать сразу
   правильно** (Asia/Yerevan; валюта — по карте, обычно USD или AMD): позже их не сменить без нового кабинета.

## Профиль
- Описание по-русски, 3 строки: кто мы («SMM и ролики для бизнеса в Ереване») → обещание («Будьте на виду») →
  призыв («Напишите в WhatsApp ↓»). Армянская строка — позже (G8).
- Ссылка — `yereva.am` (когда будет визитка) или ссылка на WhatsApp.
- 3 закреплённых публикации до старта: кто мы, что делаем, как с нами работать. Делает студия (`--studio yereva`).
- Актуальное (Highlights): «Кейс», «Услуги», «Контакты» — когда появится содержимое.

## Прогрев (первые 7 дней)
- Профиль заполнить **один раз** целиком; не менять имя, ник, описание по много раз в первые недели.
- Каждый день 15–30 мин: лента ниши (бизнес Еревана, SMM, недвижимость), лайки, осмысленные комментарии,
  5–10 подписок в день на местные аккаунты. Без массфолловинга, без сервисов автоматизации.
- Первые 3–4 дня — без публикаций, потом 3 закреплённых, далее Reels по плану (3–5 в неделю,
  `studios/yereva/CLAUDE.md`).
- Рекламу с аккаунта — не раньше, чем через 2–3 недели живой активности.

## Публикация
- Формат — выход `instagram-reels` студии (`python -m studio platforms instagram-reels`).
- Карточка загрузки — `python -m studio --studio yereva publish <проект> --out instagram-reels`; загружает человек
  через приложение или Meta Business Suite (планировщик, кросспост Reels на страницу Facebook); после —
  `publish --done --url <ссылка>`.
- Геометка «Ереван», 3–5 хэштегов, отметка ИИ-контента — по `package.ai_label`.
