# Радар бизнесов по Google Maps

Записано 2026-10-28. **Отложен** до ворот прогресса ([`README.md`](README.md), «Ворота прогресса»): довольный клиент
№1 и рост охвата у клиента и у страниц агентства. Не SaaS — внутренний инструмент. Ниже — проект, чтобы не
придумывать заново.

## Задача
Просканировать город (район) и найти бизнесы сферы услуг со слабыми соцсетями → шорт-лист с персональным аудитом для
предложения SMM.

## Конвейер
```
сетка района → Places API (поиск) → детали → сайт → ссылки на соцсети
 → метрики Instagram → скоринг → Google Sheets / CRM → мини-аудит
```

| Шаг | Как | Подводные камни |
|---|---|---|
| Поиск | Google Places API (New): Text Search по категориям; для недвижимости — тип `real_estate_agency` | один запрос Text Search — максимум 60 мест (Nearby Search — 20): город режем на сетку, дедупликация по `place_id` |
| Детали | `rating`, `userRatingCount`, `websiteUri`, телефон, `businessStatus` | цена зависит от набора полей (field mask): сначала дешёвый поиск только ID, детали — по отфильтрованным. Ориентир — десятки долларов за город или бесплатный месячный лимит; прайс сверить перед запуском, поставить квоты |
| Соцсети | Places их не отдаёт: обход сайта бизнеса, поиск ссылок `instagram.com/`, `facebook.com/`, `tiktok.com/@` | нет сайта — ручная проверка топа |
| Метрики Instagram | Instagram Graph API, Business Discovery: подписчики, число постов, даты последних публикаций | нужно своё Meta-приложение и свой IG Business, привязанный к странице Facebook; лимиты вызовов — порциями. Личные аккаунты не видны (это сам по себе признак слабого маркетинга) |
| Facebook | дата последнего поста | публичные данные страниц требуют проверки приложения в Meta; в MVP — вручную по топу |
| TikTok | официального API для коммерческого поиска профилей нет (Research API — для исследователей) | вручную по топ-N; сторонние парсеры нарушают правила TikTok |
| Хранение | SQLite → выгрузка в Google Sheets | условия Google ограничивают хранение данных Places: `place_id` хранить можно, остальное обновлять по запросу. Прочитать условия Google Maps Platform |

**Не парсить Google Maps напрямую** (в том числе через Apify и подобные): нарушение правил Google, риск бана.
Только официальный API.

## Скоринг: «хороший продукт, плохой маркетинг»
- **Потребность (слабые соцсети):** нет ссылок на соцсети; последний пост больше 30 дней назад; меньше 1 поста в
  неделю; нет роликов за 60 дней; личный аккаунт вместо бизнес-аккаунта; нет TikTok.
- **Платёжеспособность (живой бизнес):** рейтинг ≥ 4.3, отзывов ≥ 50, свежие отзывы, есть сайт.
- **Исключить:** сети и франшизы (у них свой маркетинг), отзывов < 10, закрытые.
- **Идеальный лид:** рейтинг 4.7, 200 отзывов, Instagram молчит полгода.
- Сначала разметить вручную 30–50 бизнесов — откалибровать пороги на живых примерах.

## Недвижимость в Ереване
- Рынок маленький (порядка сотен агентств и застройщиков): весь город — одним запуском, MVP — скрипт на 1–2 дня.
- **Сегменты:** агентства (`real_estate_agency`); застройщики новостроек (текстовый поиск на ru/hy/en); частные
  брокеры — на картах почти нет, позже через list.am и Instagram вручную.
- **Доп. сигналы:** объявления на list.am есть (бизнес живой), а видеотуров в Instagram нет; контент только на одном
  языке (упущены релоканты и диаспора); только Facebook, без роликов.
- Google Maps в Ереване покрывает не всех (пользуются и Yandex, и 2GIS): для MVP хватает Google, топ — сверять руками.
- **Конфликт интересов** с клиентом №1 — решить до запуска ([`README.md`](README.md), «Риски»).

## Крючок: персональный аудит
- Одностраничник: «ваши соцсети против трёх конкурентов района».
- Сильнее: **«сделали ролик из вашего объявления»** — студия собирает Reel из публичных фото объекта лида
  (`slideshow` / `promo`), отправляем **лично**, не публикуем. Серия — `batch`.
- На втором касании — кейс клиента №1 с цифрами.

## Стек
- Python-скрипт (команда знает, студия на нём же), SQLite, выгрузка в Google Sheets; CRM-статусы:
  найден → проверен → контакт → ответил → встреча → оффер → клиент.
- Повторный скан раз в неделю: новые бизнесы, у кого «умер» Instagram.
- Веб-интерфейс — только если воронка подтвердится.
