# Таргетированная реклама Instagram и Facebook (Meta)

Записано 2026-10-28. Плейбук для клиента №1 (недвижимость, Ереван) и для страниц агентства. Роль «таргетолог» —
[`SMM_TEAM.md`](SMM_TEAM.md). Правила Meta меняются — перед запуском сверять с Ads Manager и Help Center.

## 1. Инфраструктура (один раз на клиента)
- **Meta Business Portfolio клиента**; агентство получает доступ **как партнёр**, а не логином клиента.
- Рекламный аккаунт клиента, оплата — карта клиента. Деньги на рекламу — клиента, не наши.
- Страница Facebook и Instagram Business привязаны к портфолио.
- **Отдельный WhatsApp Business для заявок из рекламы и соцсетей** — иначе кейс не посчитать ([`CASE.md`](CASE.md) §3).
- Есть сайт — Pixel + Conversions API и подтверждённый домен. Нет сайта — лид-формы и сообщения.

## 2. Правила площадки: «особая категория — жильё»
- Реклама недвижимости обязана идти в **Special Ad Category «Жильё»**, если рекламодатель из США или реклама
  показывается в **США, Канаде или ряде стран Европы**. Армении в этом списке нет (по сторонним обзорам 2026; Ads
  Manager сам потребует категорию, если она нужна, — проверять при запуске).
- **Таргет на Ереван** — обычные настройки.
- **Таргет на диаспору в США, Канаде, ЕС** — категория обязательна: возраст 18–65+, все полы, без почтовых индексов и
  исключений по гео, урезанный детальный таргет, без похожих аудиторий, у города — минимальный радиус (называют
  15 миль / 25 км для США и Канады, для Европы цифры расходятся — проверить в Help Center).
- Тексты без дискриминации («только для семей», «не для …») — запрещено правилами Meta.

## 3. Структура кампаний (старт)
| Кампания | Цель | Зачем |
|---|---|---|
| Прогрев | просмотры видео / вовлечённость | дешёвый охват роликами-турами, набор аудитории досмотревших |
| Заявки | «Лиды» (мгновенная форма) **или** «Сообщения» (WhatsApp / Direct) | тестировать оба: в Армении переписка часто работает лучше форм |
| Ретаргет | заявки | досмотревшие 50 %+, взаимодействовавшие с профилем, открывшие форму |

- 2–3 группы объявлений (аудитории) × 3–5 креативов.
- Мгновенная форма — **с вопросами квалификации**: бюджет, район, срок покупки, наличные или ипотека. Без них
  дешёвые заявки окажутся мусорными.

## 4. Аудитории
| Аудитория | Настройка |
|---|---|
| Местные покупатели | Ереван + радиус; тест: Advantage+ (подбор Meta) против интересов «недвижимость», «квартиры», «инвестиции» |
| Русскоязычные релоканты | гео Ереван + язык «русский»; поведение «живут за пределами родной страны» — проверить наличие опции |
| Диаспора | гео США / Россия / Франция и др. + интерес «Армения»; в США, Канаде, ЕС — правила жилья (§2) |
| Свои | досмотревшие видео, взаимодействовавшие с Instagram, открывшие форму |
| Похожие (lookalike) | по заявкам, когда их ≥ 100; не работает в категории «жильё» |
| Исключения | уже оставившие заявку |

## 5. Креативы
- Reels 9:16 из студии: профили `instagram-reels`, `ad-15`, `ad-30` (`python -m studio platforms`).
- Крючок в первые 2 с — район + цена + фишка; субтитры вшиты (многие смотрят без звука).
- 3–5 вариантов на группу; менять каждые 2–3 недели (выгорание креатива).
- Туры по объектам и «ролик из объявления» — те же форматы, что в органике ([`CASE.md`](CASE.md) §5).

## 6. Бюджет и тест
- От $10–20/день на кампанию (деньги клиента).
- 7 дней без правок — фаза обучения. Для выхода из обучения Meta нужно около 50 целевых событий в неделю на группу;
  при маленьком бюджете — меньше групп, шире аудитории.
- Решения — по **стоимости заявки** и **качеству заявки** (дозвон, показ объекта, сделка), а не по кликам и CTR.

## 7. Обработка заявок
- Перезвон за 5–15 минут; таблица заявок (CRM) со статусами: новая → дозвон → квалифицирована → показ → сделка.
- Источник каждой заявки (реклама / органика / какая кампания) — для кейса.

## 8. Отчёт
Еженедельно в дневник кейса ([`CASE.md`](CASE.md) §4): расход, заявки, стоимость заявки, квалифицированные, показы,
сделки. Ежемесячно — клиенту.

## 9. Реклама страниц агентства
Аудитория — владельцы бизнеса в Ереване; детальный B2B-таргет Meta урезан. Работает: продвижение лучших роликов-кейсов
($50–100/мес со 2-го месяца) + ретаргет на досмотревших. Основной канал — контент и прямые контакты.

## 10. Агенты и доступ к рекламному кабинету
- **Таргетолог-агент** готовит план кампании, аудитории, тексты, креативы (через студию), разбирает статистику.
- **Доступ к статистике** через MCP:
  - официальный Meta Ads MCP (`https://mcp.facebook.com/ads`, открытая бета с апреля 2026; по отзывам, для части
    аккаунтов доступ ещё закрыт — проверить);
  - open source: GoMarble `facebook-ads-mcp-server` (только чтение, MIT), `byadsco/meta-ads-mcp`, `brijr/meta-mcp`
    (чтение и запись), Pipeboard `meta-ads-mcp` (лицензия BSL 1.1, не чистый open source).
- **Правило:** создание и запуск кампаний, изменение бюджетов — это деньги клиента. Только человек или после явного
  «да» в чате на конкретное действие (как `publish --yes`). На старте MCP — **только чтение**.
