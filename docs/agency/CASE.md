# Протокол кейса: клиент №1 (продажа недвижимости, Ереван)

Записано 2026-10-28. Цель — сделать клиенту качественный маркетинг и одновременно собрать доказуемый кейс для страниц
агентства. Общая стратегия — [`README.md`](README.md).

## 1. Согласие — закрепить письменно
Клиент согласен быть примером (устно, 2026-10-28). Закрепить сообщением (WhatsApp достаточно) или пунктом договора.

| Можно показывать (согласовать) | Нельзя без отдельного «да» |
|---|---|
| название и бренд клиента | адреса и владельцы объектов |
| цифры: охваты, подписчики, заявки, их рост | данные покупателей и продавцов |
| съёмки, ролики, закулисье | суммы сделок, комиссии |
| лица агентов (с их согласия) | переписка с клиентами клиента |

Там же — договорённость об эксклюзиве (см. риск «конфликт интересов» в [`README.md`](README.md)).

## 2. Стартовый снимок — до первой правки профилей
Без снимка «до» кейс не доказать. Сохранить скриншоты и записать цифры в `studios/<клиент>/analytics/` (когда будет
студия; до этого — любой файл с датой).

| Метрика | Где взять |
|---|---|
| подписчики Instagram, TikTok, Facebook | профили |
| охват и просмотры за 30 дней | статистика Instagram / TikTok |
| вовлечённость (лайки, комментарии, сохранения) | статистика |
| просмотры роликов с объектами (средние) | статистика |
| заявки в неделю из соцсетей (директ, звонки) | клиент; если не считал — с этого дня считаем |
| звонки и маршруты из карточки Google Maps | Google Business Profile, статистика |
| сколько объявлений активно, где (list.am и др.) | клиент |
| как выглядели профили | скриншоты шапки, сетки, последних постов |

## 3. Цели на 90 дней — в бизнес-метриках
Главное — **заявки и показы объектов**, подписчики второстепенны. Цифры целей — согласовать с клиентом после снимка.

**Измеримость заявок — основа кейса:**
- отдельный WhatsApp или Telegram для заявок из соцсетей;
- ссылки с метками в шапке и под роликами;
- вопрос «откуда узнали о нас?» в каждой заявке.

## 4. Еженедельный дневник
Раз в неделю (понедельник): цифры недели + 3–5 строк «что сделали, что сработало, что нет». Это одновременно отчёт
клиенту и сырьё для контента агентства. Место — `studios/<клиент>/analytics/` (цифры TikTok и Instagram — через
`python -m studio --studio <клиент> analytics --set <ссылка> views=…`) и `case-log.md` студии клиента. Как дневник
становится роликами агентства — роль «летописец кейса» в [`SMM_TEAM.md`](SMM_TEAM.md).

## 5. Контент клиента (русский)
| Формат | Как в студии | Заметки |
|---|---|---|
| **Видеотур по объекту** 30–60 с | съёмка + студия: плашки, цена, субтитры, призыв (`clip`, `promo`) | крючок в первые 2 с: район + цена + фишка («3-комнатная в Арабкире, вид на Арарат, $X») |
| **Ролик из объявления** | `slideshow` / `promo` из фото объекта + цена + призыв; серией — `batch` | объём без съёмок |
| **Гиды по районам** | `listicle` | Кентрон, Арабкир, Давташен… |
| **Цены за м² по районам** | `data-story` (графики из CSV) | источник — официальная статистика Кадастрового комитета (cadastre.am), формат проверить |
| **Как купить квартиру в Армении** | `explainer` / `short-hook` | спрос у русскоязычных релокантов; факты — по источникам |
| **Лицо агента, видеоотзывы покупателей** | съёмка + студия (`clip`) | доверие |

Языки: сейчас русский. Армянский — позже, голос записывает человек (синтеза армянского в студии нет, шрифтов с
армянскими буквами тоже — понадобится доработка, ROADMAP G8). Английский (диаспора) — студия умеет, `translate`.

Быстрые победы: оптимизация карточки в Google Maps (фото, категории, ответы на отзывы) — результат за 2–4 недели.
Тест рекламы: лид-формы или сообщения Meta по объектам, бюджет клиента от ~$10/день — плейбук [`ADS.md`](ADS.md).

## 6. Контент агентства из кейса (рубрики)
1. **Дневник кейса:** «Неделя 3 с агентством недвижимости: охват ×2, вот что сработало».
2. **До и после** — профили, ролики, цифры.
3. **Закулисье** — съёмочный день, студия, как делаем ролики.
4. **Разборы ошибок локального бизнеса** — обезличенно, без публичного шейминга.
5. **Позже — данные радара:** «просканировали N агентств Еревана: X % не постят 3 месяца».

Съёмочный день у клиента = контент для клиента + закулисье для агентства: одна съёмка, два контента.
