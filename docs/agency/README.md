## Суть
1. **Продукт:** SMM и продвижение для бизнеса сферы услуг (Instagram, Facebook, TikTok).
2. **Собственная упаковка:** страницы агентства в Instagram, TikTok, Facebook.
3. **Стартовый актив:** первый реальный клиент. «Два зайца» — качественный маркетинг клиенту и его рост как живой кейс,
   из которого делается контент для страниц агентства.
4. **Позже:** радар — инструмент поиска бизнесов со слабыми соцсетями (шорт-лист для предложений).

## Стартовая позиция
| Актив | Что даёт | Состояние |
|---|---|---|

| Видеостудия | ролики кодом: профили `tiktok`, `instagram-reels`, `instagram-feed` с безопасными зонами; типы `promo`, `slideshow`, `short-hook`, `listicle`, `data-story`, `clip`, `tutorial`; ревью по таймкодам, версии, пакет к выходу, календарь, серии | 🟢 работает (ru, en) |
| Мультистудия | студия на клиента (`--kind client`) и на агентство (`--kind brand`) со своим бренд-китом | 🟢 есть, студий агентства ещё нет |
| Опыт публикации | канал Notes From The Mind, часовой ролик опубликован через API | 🟡 YouTube, не наши площадки |
| Разработчики в команде | радар и доработки студии своими силами | 🟢 |
| Страницы агентства | — | 🔴 нет |
| Оффер, цены, позиционирование | — | 🔴 нет |

Ограничения студии (проверено 2026-10-28):
- Публикация через API — только YouTube. Instagram, Facebook, TikTok — вручную (карточка `publish`) или через Meta
  Business Suite / TikTok Studio.
- Аналитика: YouTube — API и CSV; TikTok и Instagram — цифры руками (`analytics --set`).
- Армянского нет: нет профиля `hy` в `studio/lang.py`, в шрифтах `assets/fonts/` 0 армянских глифов, у Edge TTS нет
  голосов `hy-AM`. Русский — полностью (голоса Edge `ru-RU-DmitryNeural` и др., кириллица в шрифтах).
- Студия рисует кодом. Живые кадры (объекты, агенты, интерьер) снимаем сами; студия даёт плашки, субтитры, цены,
  заставки, слайдшоу из фото, графики.

## Позиционирование и оффер
- **Узкая ниша сильнее «SMM для всех»**: «SMM для недвижимости в Ереване». Кейс клиента напрямую убеждает похожих.
- Связка с радаром на будущее: «мы находим бизнесы на картах и делаем так, чтобы клиенты находили их».
- Линейка (цены — по рынку Еревана, изучить 5–10 агентств):
  - вход — бесплатный мини-аудит или платная оптимизация карточки в Google Maps (быстрый результат);
  - основа — ведение Instagram + TikTok, N роликов в месяц, ежемесячный отчёт;
  - допродажа — таргет, съёмочный день.
- Посчитать, сколько клиентов тянет один человек, — для экономики.

## Площадки агентства
- **Instagram** — витрина и продажи в директе (владельцы локального бизнеса там). Основная площадка.
- **TikTok** — охват и узнаваемость.
- **Facebook** — минимум: кросспост Reels через Meta Business Suite, группы местных предпринимателей.
- Лицо основателя в кадре: в B2B для малого бизнеса личный бренд работает лучше безликого агентства.
- Частота — 3–5 роликов в неделю на основной площадке.

## Этапы
| Этап | Что делаем | Выход |
|---|---|---|
| **0. Фундамент** (неделя 1) | письменное согласие клиента (объём — [`CASE.md`](CASE.md)), стартовый снимок до первой правки, отдельный канал для заявок из соцсетей; аккаунты агентства (IG Business + страница FB, TikTok); две студии (`/new-studio`); техника | снимок зафиксирован, студии с утверждённым демо стиля |
| **1. Кейс + свои страницы** (недели 1–12) | клиент: съёмочный день в неделю, 3–5 роликов в неделю, карточка в Google Maps, тест рекламы на его бюджет. Агентство: дневник кейса, 3 ролика в неделю. Еженедельный дневник цифр | ворота прогресса пройдены |
| **2. Команда агентов** (параллельно с этапом 1, после студий) | общие роли вместо привязки к одному каналу, дневник кейса, летописец — [`SMM_TEAM.md`](SMM_TEAM.md), ROADMAP этап G | роли работают для любой студии |
| **3. Радар** (после ворот) | [`RADAR.md`](RADAR.md) | шорт-лист, персональные аудиты |
| **4. Продажи** | 15–20 касаний в неделю: ролик из объявления лида, на втором касании — кейс с цифрами | 2+ новых клиента, конверсия воронки понятна |

Время на старте: клиент ~50 %, страницы агентства ~30 %, остальное — студии и агенты.
Ритм недели: Пн — план и цифры; Вт — съёмочный день у клиента (тот же день — закулисье для своих страниц: одна съёмка,
два контента); Ср–Чт — монтаж через студию, публикации; Пт — свои страницы, разработка.

## Ворота прогресса (когда запускать радар)
Предложено 2026-10-28, пользователь может поправить цифры. Проверка через ~8–12 недель.

| Сторона | Критерий |
|---|---|
| Клиент доволен | продлил на 3-й месяц и дал отзыв (лучше видео) |
| Охват клиента | просмотры роликов ≥ 2× от стартового снимка |
| Заявки клиента | заявки из соцсетей растут, есть цифры по неделям |
| Страницы агентства | ≥ 3 ролика в неделю 8 недель подряд; первые 3–5 входящих обращений от бизнесов |

## Риски
| Риск | Что делаем |
|---|---|
| **Конфликт интересов:** радар найдёт конкурентов клиента в том же городе | обсудить с клиентом до публикации кейса: без эксклюзива (явно в договоре) / эксклюзив за доплату (тогда смежные ниши: застройщики, ремонт, дизайн, мебель) / разные сегменты (клиент — вторичка, мы — новостройки) |
| Кейс слабый или медленный | показывать процесс, не только цифры; быстрые метрики из Google Maps |
| Клиент передумает насчёт показа | письменное согласие с объёмом сейчас |
| Заявки не посчитать — кейс только об охватах | отдельный WhatsApp/Telegram для заявок из соцсетей, ссылки с метками, «откуда узнали» |
| Блоки Instagram за массовые сообщения (этап 4) | прогрев аккаунта, умеренный объём, звонки и визиты |
| Правила API (Google, Meta, TikTok) | только официальные API, хранение данных по правилам — [`RADAR.md`](RADAR.md) |
| Реклама на диаспору в США, Канаде, ЕС попадает под правила «жильё» | урезанный таргет там — заложить заранее, [`ADS.md`](ADS.md) §2 |
| Агент тратит деньги клиента в рекламном кабинете | запуск и бюджеты — только человек или явное «да»; MCP — только чтение, [`ADS.md`](ADS.md) §10 |
| Скиллы сообщества с доступом к аккаунтам | читать до установки, минимальные права, [`SMM_TEAM.md`](SMM_TEAM.md) |
| Публичные разборы чужих бизнесов | обезличивать или с разрешения |
| Работа и разработка съедают продажи | у каждой функции — владелец и время в неделе |
