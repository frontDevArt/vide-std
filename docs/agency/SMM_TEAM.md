# SMM-команда агентов

Записано 2026-10-28. Решение: **одна команда ролей на все студии**, у каждой студии — своё досье. Порядок: сначала
студии агентства и клиента, потом агенты (ROADMAP этап G). Перед тем как писать свою роль — проверить готовые скиллы
(раздел «Готовые скиллы»).

## Принцип: агенты — роли, студия — досье
Как в настоящем агентстве: одни и те же люди ведут нескольких клиентов, у каждого клиента свой брендбук и бриф.

- **Агент = роль** (команда в `.claude/commands/` или скилл), общая для всех студий. Запускается для студии
  (`--studio <id>`), читает её досье и работает в его рамках.
- **Студия = досье:** `studio.yaml` (тип, языки, площадки, умолчания), `CLAUDE.md` студии (правила), `brand/` (бренд-кит),
  позиционирование (`channel/POSITIONING.md` или аналог для brand/client), рубрики, KPI, `analytics/`, `plan.yaml`,
  `briefs/`.

Почему не своя команда на студию: 2 студии × 8 агентов = 16 копий; правка в одной не попадает в остальные, к пятому
клиенту — хаос.

**Сейчас — антипример:** `/topic-radar` и `/topic-to-brief` жёстко привязаны к путям `studios/notes-from-the-mind/`.
Их обобщить (ROADMAP G3).

## Роли
| Роль | Что делает | Есть в студии (2026-10-28) | Надо |
|---|---|---|---|
| **Стратег** | позиционирование, рубрики, частота, KPI | `/new-studio` (позиционирование — для типа youtube) | SMM-стратегия для brand и client (G4) |
| **Редактор тем** | идеи на неделю под рубрики | `/topic-radar` — только NFTM | обобщить на любую студию (G3) |
| **Контент-план** | план на неделю и месяц, сроки | `plan.yaml`, `batch`, `calendar` | ✅ |
| **Сценарист** | бриф → сценарий | `/new-video`, `/topic-to-brief` (NFTM) | шаблон брифа для коротких SMM-роликов (G3) |
| **Продакшн** | озвучка, рендер, сборка, проверка | `voice`, `render`, `assemble`, `qa`, `review` | ✅ |
| **Упаковщик** | подпись, хэштеги, обложка | `package` | проверить под Instagram и TikTok |
| **Аналитик** | цифры, выводы | `analytics`: YouTube — API; Instagram и TikTok — `--set` руками | еженедельный дневник цифр клиента (G5) |
| **Летописец кейса** | дневник и цифры студии клиента → брифы роликов для студии агентства | — | новая роль, мост «два зайца» (G6) |
| **Таргетолог** | план рекламы Meta, аудитории, тексты, креативы, разбор статистики | профили `ad-6`, `ad-15`, `ad-30` для креативов | плейбук [`ADS.md`](ADS.md), доступ к статистике через MCP — только чтение (G7) |

**Остаётся за людьми:** съёмка, лицо в кадре, публикация в Instagram и TikTok (вручную или через Meta Business Suite /
TikTok Studio), запуск рекламы и изменение бюджетов, общение с клиентом, ответы в директе и комментариях (агент может
готовить черновики), финальное «ок».

## Готовые скиллы (обзор 2026-10-28)
Своё не пишем, если есть готовое: берём, адаптируем под досье студии (рубрики, язык, бренд), отбрасываем лишнее.
Отбор и проверка — ROADMAP G2.

| Источник | Что внутри | Статус | Как можем использовать |
|---|---|---|---|
| Каталог плагинов claude.ai: **Marketing** (Anthropic) | campaign-plan, content-creation, draft-content, brand-review, competitive-brief, performance-report | официальный | стратег, сценарий, отчёты |
| Каталог: **Social Media Skills** | 106 скиллов: стратегия, тексты, видео, рост на площадках, публикация, аналитика | сообщество | выборочно: подписи, карусели, «до/после», закулисье |
| Каталог: **instagram** | чтение и ответы на комментарии и директ через Instagram Graph API | сообщество | роль «комьюнити» — черновики ответов |
| Каталог: ads-аналитика (HYPD, Windsor.ai) | разбор Meta Ads: аудитории, креативы, расход | сообщество / партнёр, внешние сервисы | таргетолог — после проверки |
| GitHub `coreyhaines31/marketingskills` | ~50 маркетинговых скиллов, в т. ч. `social-content`, реклама, копирайтинг | open source | сценарист, таргетолог (тексты) |
| GitHub `charlie947/social-media-skills` | 17 скиллов для соцсетей, основа — голос бренда | open source | голос бренда студии |
| GitHub `OpenClaudia/openclaudia-skills` | 56+ скиллов: контент, соцсети, реклама, аналитика, аутрич | open source | выборочно |
| Meta Ads MCP — официальный и open source | статистика и управление рекламой Meta | см. [`ADS.md`](ADS.md) §10 | таргетолог, только чтение |

**Правило безопасности:** скиллы и плагины сообщества читать целиком до установки — это инструкции, которые агент
выполнит, плюс доступ к аккаунтам. Плагины с доступом к Instagram и рекламному кабинету — только официальные или
проверенные, с минимальными правами.

## Связь студий: летописец
```
студия клиента                                    студия агентства
  analytics/ (цифры недели)  ─┐
  case-log.md (что сделали)  ─┼─► летописец ─► бриф «Неделя N» ─► /new-video ─► ролик
  ролики, закулисье          ─┘
```
Раз в неделю, после дневника клиента. Летописец читает только то, что разрешено согласием клиента
([`CASE.md`](CASE.md) §1).
