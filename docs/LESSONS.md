# Уроки из первого прогона («Зашёл на минутку», 30 с)

Разбор реальных логов: что стоило времени, что делать один раз, какие ошибки не повторять.
Всё перечисленное уже встроено в студию — этот файл объясняет, *почему* она устроена так.

## 1. Делается ОДИН раз на машину (а не в каждой сессии)

| Что | Было в логах | Теперь |
|---|---|---|
| TTS-движок | ~10 итераций сборки RHVoice из исходников в `/tmp` (пропадает с сессией) | `bash tools/setup_rhvoice.sh` → `tools/rhvoice/`, повторный запуск мгновенный |
| Проверка окружения | ручные `which`, `curl`, разбор прокси | `python -m studio doctor` |
| Шрифт, палитра, телефон, иконки | писались с нуля внутри одного `render.py` | библиотека `studio/gfx.py` + шаблоны `studio/templates.py` |
| Тайминги субтитров | ручная правка `audio.py` через `sed`-подобные замены | `studio/timing.py` + `studio/subs.py`, общий алгоритм |
| Микс и громкость | подбор на глаз | `studio/audio.py`: цель LUFS + лимитер + проверка в QA |
| Проверки | набор разовых команд ffprobe | `python -m studio qa` → `qa/report.md` + листы кадров |

## 2. Ошибки, которые съели время — и правило против каждой

### Окружение и сеть
- **pip/npm/HuggingFace закрыты прокси, GitHub открыт** (облачная сессия). → Сначала `doctor`; ставим то,
  что собирается из GitHub. Политику прокси не обходим, 403 не ретраим.
- **API открыт, а хост с результатом закрыт** (рабочая сеть, 2026-11-09: `api.kie.ai` отвечает, файрвол рвёт TLS к
  `tempfile.aiquickdraw.com`) — кредиты списаны, картинки нет, повтор платил бы заново. → Платная задача сразу
  пишется на диск (`assets/images/pending.json`), повтор докачивает её без оплаты; до оплаты — проба хоста файлов;
  `images --defer` — оплатить здесь, скачать из открытой сети. Сам фильтр не обходим (`docs/IMAGES.md`).
- **Локально (Claude CLI на своём компьютере) всё иначе**: обычно работает `pip install edge-tts`/`piper-tts`
  — это лучшее качество голоса. Бэкенд меняется одной строкой в `project.yaml`.

### Сборка RHVoice (все пять граблей зашиты в скрипт)
1. нет сабмодулей `cmake/thirdParty/sanitizers` и `CCache` → `add_sanitizers` unknown;
2. shallow clone без тегов → падает `VersionFromGit` → ставим локальный тег;
3. пустые каталоги неинициализированных голосов → FATAL в `data/voices/CMakeLists.txt` → удаляем;
4. boost лежит кусками в `external/libs/boost/libs/*/include` → собираем один include-каталог;
5. tclap `ValueArg<T>(const ValueArg<T>&)` не компилируется новым gcc → `sed`.

### Shell
- **RHVoice-test читает stdin и «съедает» ввод `while read`** → каждая вторая строка теряла первую букву.
  Правило: внешним процессам всегда `stdin=/dev/null`, текст — только через файл (`-i`).
- **cwd сбрасывается между командами** → только абсолютные пути / `cd X && ...` в одной команде.
- **`pkill -f "шаблон"` убил собственную команду** (шаблон совпал с её же текстом, exit 144).
  Правило: не убивать по шаблону; фоновые задачи запускать через `run_in_background` и ждать уведомления.
- **`tail -2 a b`** с несколькими файлами → ошибка; писать `tail -n 2`.
- **Команда > 600 с уходит в фон**, а цикл ожидания `until ! pgrep` тоже уходит в фон и висит.
  Правило: длинный рендер — сразу в фоне, с лог-файлом; прогресс — по логу, не по `pgrep`.
- **`| head` в конце команды рвёт pipe**, и python-скрипт может не дописать файл (BrokenPipe).
  Правило: вывод в файл, читать файл.

### Озвучка и тайминг
- Синтез по фразам даёт неестественную интонацию на запятых; по предложениям — нужны точки внутри.
  Решение: строка = предложение (синтез целиком), `|` = точка синхронизации внутри; граница ищется
  по слогам и притягивается к реальной паузе в аудио.
- **Ложные паузы** (смычка согласных «ч/т») сбивали деление. Решение: окно поиска вокруг оценки + выбор
  самой длинной паузы, иначе — оценка.
- Темп подбирался вручную прогонами 100/110/115/120/130. Теперь `rate: auto` подбирает сам под
  `target_duration` в диапазоне `rate_range`, а если не влезает — **останавливается и просит сократить
  текст**, а не ускоряет речь до неестественной. То же при `rate` числом: речь длиннее `target_duration` → `voice`
  останавливается (P1.2), а не сжимает последнюю сцену.
- Речь не обрезаем никогда: длительность = речь + паузы, остаток раскладывается в паузы и хвост.
- **Обрывы на стыках фраз** (ElevenLabs, claude-limits, 2026-11-09): «кажется, что он продолжает говорить, а его
  обрывают». Три причины разом: (1) контекст соседних строк (`previous_text`/`next_text`) — модель читает строку
  как середину речи, без конца предложения, и в хвосте начинает следующую фразу (0,1–0,4 с цифровой тишины, потом
  обрубок); (2) TRIM резал хвост на −45 dBFS с гашением 20 мс — отрезал последние ~0,1 с естественного затухания;
  (3) паузы 0,26/0,51 с. Без музыки слышно всё. Решение: `tts.context: false` для коротких роликов, TRIM хвоста
  −60 dB / 50 мс, паузы 0,42 (предложение) / 0,6 (сцена). Проверка — `qa` «Стыки речи: фразы не обрываются»
  (`tts.tail_issues`, `qa.MIN_GAP`): называет строки с обрывом, чужим началом и паузой встык (< 0,3 с после
  предложения, < 0,45 — на склейке сцен). Старый кэш TRIM не пересчитывает — исправить можно только пересинтезом
  (платно). С 2026-11-10 — правило всех студий (корневой CLAUDE.md), шаблон проекта ставит `context: false`.

### Рендер
- Полный рендер 900 кадров на 2 ядрах ~10+ мин; кадры собирались вручную на 2 сегмента.
  Теперь: кадры идут в ffmpeg через pipe, сцены рендерятся параллельно и **кэшируются** —
  правка одной сцены = перерендер одной сцены.
- Motion blur двоил текст при малом числе сэмплов. Правило: число сэмплов ∝ смещению в пикселях.
- Всё дорогое (размытие свечения, текст, иконки) — один раз в спрайт, в кадре только композиция.
- **Сначала контрольные кадры (`stills`), потом полный рендер.** Дешёвая итерация по картинке.
- Найдено в этом прогоне: на стыке сцен прыгала яркость экрана телефона. Правило: всё, что видно
  через склейку (позиция ленты, затемнение, фон), — это непрерывное состояние, а не локальная
  анимация сцены. Фон — функция глобального времени.

### Проверка (не отправлять, не проверив)
- Длительность и число кадров через ffprobe, полное декодирование `-f null`, звук есть и слышен,
  музыка ≥ 14 LU тише голоса, последнее слово кончается до конца файла, субтитры ≤ 2 строк и влезают
  по ширине, кадры из ГОТОВОГО файла глазами. Всё это — `python -m studio qa`.

## 3. Что ещё делает работу комфортнее
- `.claude/settings.json` разрешает команды студии без постоянных подтверждений.
- `python -m studio status` — состояние из файлов, а не из памяти сессии: новая сессия сразу знает,
  где остановились.
- Субтитры дополнительно пишутся в `.srt`/`.vtt` — их можно загрузить на YouTube отдельно.
