# Архитектура студии

```
тема ─► project.yaml ─► outline.md ─► script/chNN.yaml ─► [voice] ─► build/timeline.json
                                                            │            │
                                                     build/tts/*.wav     ├─► [stills] ─► qa/stills_*.png
                                                     (кэш по тексту)     ├─► [render] ─► build/render/chNN/sNN.mp4 (кэш по сцене)
                                                                         └─► [assemble] ─► mix/levels.json (+ chapters/*.mp4 по --chapters)
                                                                                               └─► final/<slug>.mp4 + .srt/.vtt
                                                                                                        └─► [qa] ─► qa/report.md
```

## Модули `studio/`
Порядок слоёв (после этапа 2 `REFACTOR_PLAN`): `cli` → `commands/` → фазы (`validate`, `tts`/`timing`, `render`,
`assemble`/`audio`, `qa`) → рисование (`packs/` → `gfx`/`anim`/`motion`/`style`) → основа (`project`/`config`/`workspace`,
`textutil`, `lang`). Нижний слой не импортирует верхний; пути к данным — только через `workspace`/`project`.

| Файл | Что делает |
|---|---|
| `cli.py` | разбор аргументов `python -m studio …`; сами команды — `commands/<команда>.py` (`add(sp)` — аргументы, `run(a)` — код возврата, тяжёлые импорты внутри `run`); новая команда = модуль + имя в `commands.NAMES` |
| `validate.py` | проверка сценария: `check(proj)` → `Report` (ошибки, предупреждения, слова, оценка речи); печатает команда |
| `project.py` | загрузка `project.yaml` + глав, пути внутри проекта (`build/`, `qa/`) |
| `workspace.py` | где данные студии (workspace): `projects/`, `channel/`, `briefs/`, `research/`, `logs/`, `.env`, `tools/`; студии (ROADMAP A1) — `default` (корень) и `studios/<id>/` с `studio.yaml`: `studio(id)`, `studios()`, `find(slug)`, `owner(проект)`; `current()` — текущая (`--studio`), `use()` — другая; `load_env` — `.env` студии, запасной — корневой; `secret(имя, ws)` — секрет студии без общего os.environ (свой `.env` → окружение → корневой, ROADMAP A3). Остальной код пути данных сам не склеивает |
| `voices.py` | голос студии (ROADMAP A3): `voices:` по языкам из `studio.yaml` — слой tts между `defaults` и project.yaml, `env:ИМЯ`; `max_accents`; замеры темпа голоса на студию — `studios/<id>/voices.yaml` |
| `textutil.py` | текст строки: сегменты `\|`, текст для TTS и для экрана, вес слогов для оценки длительности, ёмкость субтитров |
| `lang.py` | профиль языка (`language`): голоса по умолчанию, фраза проверки TTS, ориентир темпа (`wpm`), «чужой алфавит» для validate |
| `assets.py` | ассеты проекта (ROADMAP C2): `assets/` + `assets.yaml` (файл, источник, лицензия, кто дал); `refs` — медиа в `params` сцены, `issues` — validate, `qa_check` — строка QA, `fingerprint` — содержимое файлов в ключе сцены; у нарезки ищет и в папке исходника ([ниже](#медиа-слой-roadmap-c2)) |
| `imagegen.py` | картинки сцен (ROADMAP C5, [`IMAGES.md`](IMAGES.md)): схема `images:` и запросы `image:`, ключ кэша `assets/images/<ключ>.png`, `plan`/`estimate` — работы и смета, `generate` — бэкенды `kie`/`fake`/`none` и локальный `rembg` (`tools/rembg-venv/`), `entries`/`register` — учёт в `assets.yaml`; команда — `commands/images.py` |
| `media.py` | декодирование для шаблонов `media`: фото (кэш), `Video` — кадры видео потоком из ffmpeg нужного размера и fps (подряд — чтение, назад или далеко вперёд — перезапуск с `-ss`, за концом — стоп-кадр), `audio` — звук исходника (моно float32), `envelope` — громкость по кадрам |
| `kinds.py` | типы роликов (ROADMAP C1): `kind` в `project.yaml` → голос, пределы длительности, поля `brief:`, проверки validate/status/qa ([ниже](#типы-роликов-roadmap-c1)) |
| `config.py` | схема `project.yaml`: ключи, типы, значения по умолчанию, `schema_version` и `migrate()`, ⚠️ на неизвестный ключ |
| `tts.py` | бэкенды TTS, кэш, обрезка тишины, поиск пауз |
| `timing.py` | раскладка: строки → биты → сцены → кадры; подбор темпа под точную длительность |
| `calibration.py` | замер слов/мин голоса после `voice` → `build/voice_calibration.json` и `voices.yaml` студии; темп для `validate`/`status`: проект → студия → язык |
| `subs.py` | нарезка субтитров по битам, перенос ≤ N строк по реальной ширине шрифта, SRT/VTT |
| `style.py` | `Style` — палитра, настроение, шрифты по ролям, фон, камера, режим субтитров; строится из `project.yaml → style` (с китом — из `style.kit`), неизменяемый; `use()`/`active()` — стиль для хелперов gfx без `style=` |
| `brand.py` | бренд-кит студии `brand/brand.yaml` (ROADMAP A2, [`BRAND.md`](BRAND.md)): проверка, `resolve` — `style.brand` → `cfg["style"]["kit"]` в `project.load` |
| `anim.py` | прогресс и кривые для всех пакетов: `span(t, a, b)` — отрезок, `ramp(t, start, dur)` — длительность; кубические `eo`/`eio`/`eob`/`ei`, CSS-кривые STYLE §6 (`ease_out_expo`, `ease_in_out`, `ease_in`), `spring` |
| `gfx.py` | шрифты, easing (из `anim`, `prog` = `span`), спрайты со свечением, фон, иконки, телефон (`style=` у хелперов, стиль — в ключе кэшей) |
| `packs/` | пакеты шаблонов сцен: `registry.py` (реестр с пространствами имён `core.title`, `lab.flow`, `project.<имя>`; старые плоские имена — алиасы; коллизия → ошибка; `Param` — тип, умолчание, описание; `formats`), `base.py` (`Template`), `core/` (title, statement, bullets, counter, outro), `phone/` (телефон с лентой + 5 шаблонов первого ролика), `lab/` (пресет канала: `background` — фон и камера (`composite_camera` — affine только по плиткам с контентом, P3.1), `elements` — примитивы и фирменные элементы, `triggers` — `at`, `check` — проверка `at` для validate/voice, `base` — `LabTemplate`, `hero`/`crowd`/`templates` — шаблоны), `commerce/` (на основе lab: `elements` — бирка, чек, цепь, `thousands`; миксины `PriceTag` и `Receipt`; шаблоны `price_tag`, `number`), `media/` (ROADMAP C2: `base` — `MediaTemplate`: рамка `box`, форма, вход/выход, подпись, подложка «под обрез» вне проверки зоны (`safe_draw`); `image`, `video` — video/screen/clip, `brand` — logo_sting/product_card); `reference.py` — справочник шаблонов в Markdown из метаданных (`templates --md`, блок в `SCENE_SPEC.md`, P5.3); `load_project_templates` — шаблоны проекта в пространство `project` |
| `templates.py`, `lab.py` | прежние входы (шаблоны проектов, тесты): те же имена из `packs/`; запись `studio.lab.<имя> = …` доходит до модуля пакета |
| `motion.py` | тайминги STYLE §6 (кадры @30) и составные анимации (кривые — из `anim`, `prog` = `ramp`), камера как функция глобального времени |
| `sfx.py` | синтез звуков появления, дорожка SFX по событиям шаблонов (−28…−32 dB к голосу) |
| `render.py` | непрерывное состояние между сценами, параллельный рендер с кэшем, stills. Процессов по умолчанию — половина логических ядер (`default_workers`, `render.workers` в `project.yaml` перекрывает); сцена длиннее 1,5 × `CHUNK` (120 кадров) рендерится кусками в `build/render/chNN/parts/` (свой ключ у куска — прерванный рендер докачивает), куски склеиваются `concat -c copy` в `sNN.mp4` и удаляются. `--draft` (`prepare(draft=True)`): ctx W/H вдвое меньше (шаблоны рисуют в долях — `self.u`/`self.z`), `ultrafast`, сцены в `build/render-draft/` (`s["render_dir"]`), ключ отличается размером и пресетом. `prepare()` (сцены + состояние на стыках + ключи; 85 % цены — хэш кода шаблонов) внутри `prepare_once()` считается один раз на (проект, draft, cfg, главы, `timeline.json`) и отдаётся копией; CLI оборачивает так каждую команду (assemble + sfx, stills + поля, `all`) |
| `log.py` | лог каждой команды: вывод в консоль дублируется в `projects/<slug>/logs/<команда>-<время>.log` (без проекта — `logs/` рабочей области), трассировка падения — туда же; хранятся последние 20 на команду; `status`/`templates` (`LOG = False`) лог не пишут |
| `codehash.py` | хэш кода рисования для ключа сцены: файлы ищутся по импортам шаблона сцены, а не по списку |
| `safezone.py` | вёрстка: рамка контента сцены (шаблон на прозрачном слое) против полей кадра → ⚠️ в `stills` и `qa` |
| `audio.py` | дорожка голоса по таймлайну (кусками по 30 с, int16 — память не растёт с длиной) + звук исходников сцен (`media_track`: `audio_clips()` шаблона — клип, видео с `audio: true`), процедурная музыка, sidechain, LUFS |
| `music.py` | музыка и ритм (ROADMAP C3): файл трека (проект, библиотека студии `brand/music/` + `music.yaml`), ритм-трек кодом, доли и сильные доли (онсеты numpy → темп автокорреляцией → доли DP Ellis → пик онсета; кэш `build/mix/beats-<sha1>.json`), `sync` — склейки в долю (`snap` из `timing.layout`), подложка по главам с кроссфейдом (`bed`), validate/qa (лицензия, «Склейки в долю» по звуку итога) |
| `clean.py` | `clean`: удаляет из `build/` пересобираемое (рендер, черновой рендер, главы, микс, финал — кроме `--keep-final`, TTS вне таймлайна, старые `build/*.log`), отчёт по группам; `timeline.json`, калибровка и TTS из таймлайна остаются, у платного синтеза TTS не трогается вовсе. `--older-than 30d` — только давно не менявшиеся проекты (без проекта — все такие) |
| `assemble.py` | склейка сцен прямо в финал без перекодирования видео (список concat — во временной папке); `--chapters` — ещё файлы глав `build/chapters/chNN.mp4` (иначе их нет: это копия `render/`) |
| `qa.py` | автопроверки + листы кадров из готового файла |
| `status.py` | какие фазы готовы (по хэшам и файлам) и что делать дальше |
| `selftest.py` | `selftest`: фикстура `tests/fixtures/gallery` → validate → voice (`fake`) → render → assemble → qa → сравнение с `tests/golden/` (timeline и `.srt` байт в байт, кадры — с допуском, в том числе вынутые из MP4); `--kinds` — демо каждого типа ролика `tests/fixtures/kinds/` до QA PASS |

## Студии (ROADMAP A1)
Студия (workspace) — канал, бренд или клиент. Раскладку папок знает только `workspace.py`:
```
./                       студия default: projects/ (старые проекты), logs/, .env, tools/ (голоса — общие)
studios/<id>/            studio.yaml (+ voices: по языкам), CLAUDE.md, channel/, briefs/, research/, projects/, .env (свой ключ и голос, запасной — корневой), voices.yaml (замеры темпа)
```
- `python -m studio --studio <id> <команда>` делает студию текущей на время команды (`workspace.use`); `new --studio <id>`
  — то же для нового проекта. Без флага текущая — `default`, а slug, которого в ней нет, ищется во всех студиях
  (`workspace.find`); один и тот же slug в двух студиях — ошибка с просьбой указать `--studio`.
- Настройки проекта: `config.DEFAULTS` → `defaults:` из `studio.yaml` студии-владельца (`workspace.owner` — по пути
  проекта) → `project.yaml`. `defaults` проверяются той же схемой, что и `project.yaml`. Заготовка `new` — своя
  `projects/_template` студии, иначе общая из корня; `language`/`format` без флагов — из `defaults` студии.
- Ключи кэша TTS и рендера от пути проекта не зависят (хэш кода — по содержимому файлов), поэтому перенос проекта
  в студию вместе с `build/` ничего не пересчитывает. `python -m studio studios` — список студий и их проектов.
- Новая студия (ROADMAP A4): `python -m studio new-studio <id> --name … --kind … --lang … --platforms …` копирует
  заготовку `studios/_template/` (не студия: `_`-папки `studios()` пропускает) — `studio.yaml` с голосами по языкам,
  `brand/brand.yaml`, `CLAUDE.md`, для `youtube` — `channel/POSITIONING.md` — и создаёт проект демо стиля
  `projects/<id>-style/` (сценарий `demo/ch01.yaml` на языке студии, шаблоны `core.*` — все форматы). Мастер
  Claude — `/new-studio`: анкета из описания, кит по референсу (BRAND.md), демо 10–15 с на утверждение.

## Типы роликов (ROADMAP C1)
`studio/kinds.py` — `kind` в `project.yaml` (нет — `explainer`; в cfg ключ не попадает, ключ кэша рендера старых проектов
тот же). Тип — запись `Kind`: голос (`voice=False` — `tts.backend: none`, `tts.synth` такой строки не синтезирует),
пределы длительности и нужна ли точная, обязательные поля `brief:` и файлы брифа, музыка как содержание, звук исходника
как речь (`source_audio`, clip), `needs` — недостающий слой движка (тип принимается, validate ⚠️, демо — в той задаче;
после C4 не осталось ни у одного типа: `data-story` строится на `chart`). Проверки: `kinds.issues` — в `validate`,
`kinds.brief_missing`/`missing_files` — фазы «1 Бриф» и «1б Материалы» в `status`, `kinds.qa` — строки QA. Демо по типу —
`tests/fixtures/kinds/<тип>/`: `tests/test_kinds.py` — validate и тайминг, `selftest --kinds` — до QA PASS (каждый выход
из `deliverables`: promo — 9:16 и 1:1).

## Медиа-слой (ROADMAP C2)
Файлы — `projects/<slug>/assets/`, их происхождение — `assets.yaml` (`studio/assets.py`). Сцена ссылается на файл путём от
папки проекта в `params` — ссылкой считается любая строка с расширением медиа (`assets.refs`), поэтому шаблонам не нужно
объявлять, какие параметры — файлы. validate: нет файла — ❌, нет записи или лицензии — ⚠️; qa «Ассеты: источник и
лицензия» — ❌. `prepare` кладёт в ctx `roots` (папка проекта, у нарезки ещё исходника) и добавляет в ключ сцены
`assets.fingerprint` — sha1 содержимого файлов (кэш по mtime и размеру): фото заменили тем же именем — сцена устарела;
у сцен без медиа ключ прежний. `studio.assets` — в `codehash._NOT_DRAWING` (данные, а не рисование).
Шаблоны — пакет `packs/media/`; дорогое (подгонка фото под масштаб, маски, тени, волна звука) — в `setup`, в `draw` —
окно `resize(box=…)` с субпиксельным сдвигом (Ken Burns и параллакс без дрожи). Видео не грузится в память: `media.Video`
отдаёт кадры потоком; сцены рендерятся подряд, кусок рендера (`CHUNK`) начинается с `-ss`. Фото и видео без `box` — на весь
кадр под обрез: это подложка, `MediaTemplate.safe_draw` отдаёт safezone только подпись и элементы поверх (у шаблонов с
рамкой — всё). Звук: шаблон с `audio_clips()` → `audio.media_track` кладёт звук исходника в дорожку голоса — sidechain
приглушает музыку под ним, итог нормализуется по LUFS; так `clip` звучит речью исходника без синтеза (`tts.backend: none`,
QA «Звук исходника звучит»). `render --alpha mov|webm` (`render.export_alpha`) — кадры шаблонов на прозрачном без фона и
субтитров одним проходом в ProRes 4444 (`yuva444p10le`) или VP9 (`yuva420p`), `build/final/<slug>.alpha.<fmt>`.
CSV графиков (`kit.chart`, ROADMAP C4) — тоже ассеты (`assets.DATA_EXT`): у источника данных те же правила, что у фото.

## Библиотека шаблонов и галерея (ROADMAP C4)
Пакет `packs/kit/` — общие шаблоны для любой палитры и формата: `chart` (столбики, линия, круг из CSV или `values`),
`timeline`, `steps`, `compare`, `map` (заглушка: сетка-проекция и булавки), `quote`, `testimonial`, `lower_third`,
`cta_end`, `chapter_bumper`; у `commerce.price_tag` появился алиас `price_tag`. База `KitTemplate`: триггер `at` (бит |
секунды | слово, как у media и lab; `word_triggers = True` — слова проверяет `lab/check.trigger_errors` в validate и
voice), `item_at` (элемент списка: `at` → бит `first_beat + i` → равномерно), `place` (блок «заголовок + содержимое» по
центру `self.area`), кегль `fs` (×1,18 в широком кадре, ×1,15 в высоком 9:16 и 4:5). Полупрозрачные фигуры — только
через `kit.base.Ink`: `ImageDraw` на RGBA-кадре не смешивает цвет, а записывает альфу в пиксели, и в итоговом RGB
полупрозрачное стало бы сплошным (так была залита полоса `chapter_bumper` в первом прогоне). Фикстура
`tests/fixtures/library/` — по сцене на каждый шаблон, которого нет в `gallery` (kit, commerce, media), палитра lab;
golden — `tests/golden/library/<формат>/` (timeline и по 2 кадра на сцену, плюс кадры с TikTok-субтитрами), у сцен с
видео-ассетом допуск шире (`selftest.VIDEO_TEMPLATES`: декодер ffmpeg разных версий). `test_gallery` требует, чтобы
две фикстуры вместе покрывали весь реестр. `python -m studio gallery` (`studio/gallery.py`) снимает обе фикстуры в
каждом формате воркерами (по 5 кадров на сцену) и режимы субтитров, страница — `output/gallery/index.html` (поиск,
фильтр форматов, проигрывание кадров при наведении, параметры из метаданных шаблона).
Режим субтитров проекта — `subtitles.style: plate | karaoke | tiktok`: `project.load` кладёт его в `style.subs`,
`Style.subs_mode` перекрывает пресет и бренд-кит (`Style.subs`), `subs.mode()` — размер и место полосы; без ключа cfg и
ключ рендера прежние.

## Площадки (ROADMAP B1)
`studio/platforms.py` — профили выходов: `youtube`, `youtube-shorts`, `tiktok`, `instagram-reels`, `instagram-feed` (4:5),
`square`, `ad-6/15/30`. Профиль: допустимые форматы проекта, fps, пределы длительности, безопасная зона (поля по
сторонам + прямоугольники интерфейса, доли кадра), норма громкости площадки, вшитые субтитры, кодеки и битрейт,
обложка, источник цифр с датой сверки (где площадка пикселей не публикует — оценка, это сказано в `note`).
Проект выбирает площадку ключом `platform:` (нет — проверок по площадке нет, всё как раньше): `validate` —
формат и предел длительности, `stills`/`qa` — зона площадки (`safezone.zone`), `qa` — файл (`platforms.checks`).
`studios` и `new-studio` проверяют `platforms:` студии, `new --platform` выбирает формат по площадке. Картину профиль
меняет только полями сетки вёрстки (`platforms.layout_zone` → `ctx["safe"]`, ROADMAP B2) — они в ключе сцены вместе с
верхом полосы субтитров (`subs.band_top` → `ctx["subs_top"]`), поэтому `platforms.py` не входит в хэш кода рендера.
Шаблоны читают их как `Template.safe` / `Template.area` (SCENE_SPEC).

## Выходы (ROADMAP B3)
`deliverables: [youtube, tiktok]` в `project.yaml` — несколько выходов из одного сценария. `Project.output(<id>)` —
тот же проект с `platform: <id>` и форматом площадки (формат проекта, если площадка его принимает, иначе её основной);
`Project.targets(out)` — что собирает команда. Общее у выходов: сценарий, озвучка `build/tts/` (синтез один раз),
`build/voice_calibration.json`, тайминг речи. У каждого своё: `build/<выход>/` (`timeline.json` — субтитры режутся
по ширине кадра, рендер, микс), `qa/<выход>/`, финал `output/<slug>/<выход>.mp4` + `.srt`/`.vtt` в корне студии
(проект вне `projects/` студии — `output/` в самом проекте). `voice`/`stills`/`render`/`assemble`/`qa`/`all` — по всем
выходам или `--out <выход>`; `frame` — `--deliverable` (его `--out` — файл PNG); `status` — фазы 4–8 по выходам;
`clean` — все выходы. Без `deliverables` — один выход в `build/`, всё как раньше.
Субтитры у проекта с площадкой (`platform:` или выход) стоят над нижним полем её зоны (`subs.bottom_limit` →
`ctx["subs_bottom"]`, в ключе сцены, только когда задан) и не шире её боковых полей (`subs.max_width`); без площадки —
место по формату, как до B3 (golden не меняется).

## Нарезка (ROADMAP B4)
`python -m studio cutdown <исходник> --to youtube-shorts --count 3` — длинный ролик → короткие. `studio/cutdown.py`
выбирает отрезки: подряд идущие сцены одной главы (без карточек глав и призывов исходника) длительностью `--min`–`--max`
(по умолчанию 20–60 c, не больше предела площадки); очки — цифра, вопрос, вердикт, источник, плюс крючок в первой сцене
и развязка в последней. Длительности — из `timeline.json` исходника, если он свежий, иначе оценка по темпу голоса.
`--list` — только список, `--pick ch02/s13-s15,s17` — свой отрезок (через запятую — с пропуском), `--force` — перезаписать.
Результат — обычный проект `<исходник>-cut-N/` рядом с исходником: `project.yaml` с `cutdown: {source: <slug>}`,
площадкой и её форматом; `script/<глава>.yaml` со сценами-ссылками `from: sNN` и заготовками крючка и CTA в
комментариях; `templates/` — копией исходника. Загрузка (`studio/cutrefs.py`, из `project.load`): настройки исходника
(кроме площадки, формата, глав, длительности, названия) под своими; `from:` → копия сцены исходника, свои ключи поверх;
у строк — контекст соседей из исходника (`_ctx` → `line_jobs`), поэтому ключ кэша ElevenLabs совпадает; `glow` главы
и накопленная шапка `chrome` (lab) — из исходника. `Project.src` — исходник: `bdir("tts")` нарезки — `build/tts/`
исходника (озвученный исходник → нарезке синтез не нужен; синтез нарезки ложится в тот же кэш и пригодится исходнику).
Дальше нарезка идёт обычным конвейером: `validate → voice → stills → render → assemble → qa`; `qa` проверяет предел
длительности площадки.

## Пакет к выходу (ROADMAP B5)
`python -m studio package <проект> [--out <выход>]` (`studio/package.py`; последний шаг `all`) — всё для ручной
загрузки в `output/<slug>/` рядом с `<выход>.mp4` и `.srt`/`.vtt`. Проект без `deliverables` — файлы `<slug>.*`,
финал и субтитры `package` копирует туда из `build/final/`; площадка не задана — берётся площадка формата
(`platforms.LAYOUT`), в чек-листе это сказано.
- `<выход>.cover.jpg` — кадр ролика без субтитров (`clean_frame`: `render.frame` со сценой без `subs`) в момент
  `package.cover.at` (секунды или `chNN/sNN` — 60 % сцены; по умолчанию первая сцена), кадрирование «cover» под размер
  обложки площадки (`Platform.cover`, YouTube 1280×720; без него — кадр ролика), затемнение снизу, заголовок
  `cover.text` и плашка вердикта (`cover.verdict`: `auto` — первый `params.verdict` сценария, `none` — без неё;
  у `lab` — штамп `stamp_sprite`) внутри безопасной зоны площадки. Шаблон — `COVER` ← `brand/cover.yaml` бренд-кита
  (`docs/BRAND.md`). JPEG ужимается до `Platform.cover_mb` (YouTube — 2 МБ).
- `<выход>.description.md` — название (`package.title` ← `title`), блок для копирования: описание
  (`package.description` ← `topic`), главы YouTube (`Platform.chapters`: начала глав из `timeline.json`, названия —
  `title` главы; первая 0:00, не меньше трёх, каждая ≥ 10 с — короче сливается с предыдущей; иначе глав нет и сказано
  почему), источники, хэштеги (`Platform.tags_max`: Shorts 3, TikTok/Instagram 5). Счётчики символов против
  `title_max`/`text_max`. На площадках-подписях (нет `title_max`: TikTok, Instagram — 2200 символов) источники —
  короткие цитаты сцен одной строкой («Sources: Tversky & Kahneman, 1974; …»), полные ссылки — в описании YouTube.
- Источники: цитаты `params.source.text` сцен (части через «·» вида «Автор(ы), год»; журнал, выборка, «May 2024 –
  May 2025» пропускаются) сопоставляются с полными ссылками `package.sources` по фамилии первого автора и году (ссылка
  без года — по фамилии). Цитата без полной ссылки идёт как есть, с ⚠️. Ролик получает и ссылки, которых нет в сценах;
  нарезка (B4; `package` у неё свой, не наследуется) — только процитированные, полные ссылки — из `package` исходника.
  Студия-канал (`kind: youtube` или `channel/POSITIONING.md`) без источников — ❌.
- `<выход>.checklist.md` — пункты с галочками: файл и предел длительности, итог `qa/<выход>/report.md`, субтитры
  (вшиты — не включать автосубтитры; YouTube — загрузить `.srt`), обложка, тексты, главы, источники, хэштеги,
  отметка ИИ-контента площадки (`Platform.ai`, `ai_voice`: реалистичный синтетический голос сам по себе требует
  отметки у TikTok и Meta, у YouTube — только если выдаёт себя за реального человека), язык; внизу — ❌/⚠️ пакета.
- `package.by_output.<выход>` перекрывает `title`/`description`/`hashtags`/`cover` для выхода. `package:` вне ключа
  рендера, `package.py` рендер не импортирует — правка текстов ничего не перерисовывает.

## Почему склейки не видны («как будто сделано за один заход»)
1. **Единое время.** Сцена знает своё глобальное начало (кадр). Фон — функция глобального времени,
   поэтому на стыке сцен и глав он продолжается, а не начинается заново.
2. **Непрерывное состояние.** То, что переходит через склейку (позиция ленты, затемнение экрана),
   считается заранее по всем сценам по порядку и подаётся на вход каждой сцене (`state_in`).
3. **Единая геометрия.** Телефон, субтитры, палитра, шрифт — общие для всего проекта.
4. **Один звук на весь ролик.** Голос кладётся сэмпл-точно по таймлайну, музыка — одна петля
   на весь ролик (свой трек на главу — одна подложка с кроссфейдами), громкость нормализуется один раз. На стыках глав
   звук не рвётся. Трек играет с нуля ролика — поэтому доли файла и есть доли ролика (`music.sync`).
5. **Одинаковый кодек.** Все сцены кодируются с одними параметрами и склеиваются `-c copy`.
6. **Зафиксированные решения.** Голос, темп, палитра, термины — в `project.yaml`/`outline.md`,
   а не в памяти сессии.

Закреплено тестами: фикстура gallery (2 главы, стык с `glow` и `keep`) проходит `selftest`, кадры сцен по обе стороны
стыка сравниваются с golden (`tests/test_gallery.py`, `tests/test_golden.py`).

## Длинный ролик (например, 60 минут) — по частям
Сессия Claude ограничена, поэтому работа режется так, чтобы каждая часть была законченной:

| Уровень | Размер | Что делает сессия |
|---|---|---|
| Проект | 60 мин | фазы 1–2 (бриф, план) — одна сессия |
| Глава | 4–8 мин, ~600–1100 слов, 30–80 сцен | одна сессия: сценарий → voice → stills → (рендер в фоне) |
| Сцена | 3–12 с | единица рендера и кэша |

Порядок для часа (≈ 9000 слов, ~10 глав):
1. Сессия 1: бриф + `outline.md` с главами и бюджетом слов, сквозные решения.
2. Сессия на главу: `/chapter chNN` — написать сценарий главы, `validate`, `voice`, `stills`, проверить листы,
   запустить рендер главы в фоне. После главы 1 — **зафиксировать `tts.rate` числом**.
3. Финальная сессия: `assemble` + `qa`.

Главы пишутся по порядку: позиция ленты/фон следующей главы зависят от длительности предыдущих.
Если переозвучить раннюю главу, у поздних меняется глобальное время → они станут «устаревшими»
и перерендерятся (`status` это покажет). Поэтому: правки текста — до рендера поздних глав.
