# Стиль «VOX»: разбор и перенос на студию (2026-11-09)

Задача пользователя: новая студия в стиле VOX, первый ролик — бета-демо 40–45 с «Почему у Claude быстро кончаются
лимиты и какое лекарство — Graphify и PonyTail». Картинки — Kie (ключ есть в `.env`), ElevenLabs — **не трогаем**,
пока стиль не согласован. Этот файл — шаг 0: анализ стиля. Студия, бренд-кит и демо — после ответов пользователя.

Источники внизу. Первоисточника «как устроен стиль Vox» от самой редакции нет (только интервью и вакансии), поэтому
приёмы ниже — сводка разборов, туториалов и сторонних реконструкций; конкретные HEX и шрифты Vox **не копируем**.

## 1. Что такое «стиль VOX» — два слоя

**A. Классический Vox (видеоредакция с 2014: Джосс Фонг, Джонни Харрис, Фил Эдвардс).** Журналистика прежде графики:
картинка — это доказательство, а не украшение (Фонг: думать о том, *что* показываешь зрителю). Словарь:
- документы, скриншоты и газетные вырезки, нужная фраза выделяется **жёлтым маркером**;
- архивные фото, вырезанные «стикером» (белая кромка, тень), лежат на бумажном фоне с зерном;
- карты и простые графики, поверх — рисованные от руки стрелки, круги, подчёркивания;
- крупная гротескная типографика, ограниченная палитра (бумага, чёрный, жёлтый, иногда красный);
- движение «на двойках» (~12 к/с) — ощущение ручной перекладки, а не гладкой CGI;
- мелкие детали движения задают ритм сильнее, чем крупные события;
- звук: тихая атмосферная музыка (реверб — фирменный приём Эстель Касвелл), звуки бумаги и щелчки.

**B. «Vox-style» 2025–26 (тренд AI-ютуба, бумажный коллаж).** То, что сейчас продают под этим именем:
- **рваная/резаная бумага, скотч по углам, растр (halftone), газетные вырезки, трафареты**; каждый элемент — отдельная
  вырезка со своей тенью; фон — один плоский цвет или бумага;
- **сборка кадра «сзади вперёд»**: пустой фон → элементы въезжают по одному в порядке рассказа → последней рисуется
  пометка (маркер, красная нитка между булавками, подчёркивание) → «живой постер»: углы чуть приподнимаются,
  тени дышат, растр мерцает;
- шаг движения — «stepped easing, 2–3 кадра держим», камера стоит (или один медленный наезд за кадр), никаких
  «snap / punch-in»;
- бит — 2–3 с (5–8 слов), простые склейки без переходов; звук — шорох бумаги, удар штампа, машинка, тихая музыка;
- вертикаль: меньше элементов, крупнее подписи, всё важное — в центре.

**Наш вывод:** берём из A — подачу (вопрос → механизм → доказательство → вывод, спокойный голос «давайте разберёмся»),
маркер, стрелки, карту-схему; из B — фактуру и сборку кадра. Это и есть то, что зритель сейчас узнаёт как «VOX».

## 2. Грамматика одного бита (что делаем в каждой сцене)
1. **Фон**: кремовая бумага с зерном (одна текстура на весь ролик).
2. **Предметы**: 1–3 вырезки (иллюстрация Kie, разложенная на слои) въезжают по словам озвучки, с тенью.
3. **Слово**: заголовок на полоске рваной бумаги или фраза под маркер — текст кодом, не картинкой.
4. **Пометка последней**: жёлтый маркер, красный круг/стрелка, красная нитка.
5. **Дыхание до склейки**: микродвижение, без наездов. Склейка — резкая.
Смена «события» в кадре каждые 2–3 с, смена сцены — 5–7 с (правило студии 6–8 с соблюдается по сценам).

## 3. Сценарий: структура Vox для 40–45 с
Вопрос-крючок (0–4 с) → «вот в чём дело» — механизм (4–20 с) → тезис одной фразой → решение 1 → решение 2 → вывод
в три слова. Голос — спокойный, разговорный, «мы разбираемся вместе», без хайпа. Цифры — только из первоисточника и с
плашкой источника в кадре.

**Черновик (ru; ~110 слов при 145 сл/мин ≈ 45 с — в бете ужать до ~100).** Названия в озвучке — кириллицей
(правило студии), в кадре — латиницей.

| # | Озвучка | Картинка (вертикаль) |
|---|---|---|
| 1 | Вы платите за Клода. \| Так почему лимит кончается к обеду? | рваный заголовок «ЛИМИТ ИСЧЕРПАН», вырезка песочных часов, полоса лимита 100 % под красным штампом |
| 2 | Вот в чём дело: \| Клод не помнит ваш чат. \| Каждое сообщение он заново обрабатывает весь разговор — \| с самого начала. | бумажные «реплики» чата падают стопкой, фраза «весь разговор» — под маркер |
| 3 | Первое сообщение стоит копейки. \| Тридцатое тащит за собой все двадцать девять. | столбики-ступеньки растут шагами, тридцатый — красным кругом |
| 4 | В коде ещё хуже: \| чтобы ответить на вопрос, \| он открывает файл за файлом — \| и всё это в ту же кучу. | папки-вырезки слетаются в стопку, стопка растёт до верха кадра |
| 5 | Лимит съедают не вопросы. \| Его съедает чтение. | крупная фраза, «чтение» — жёлтым маркером |
| 6 | Таблетка первая — Графифай. \| Он один раз рисует карту проекта: что с чем связано. \| И Клод спрашивает карту, \| а не читает всё подряд. | рецептурный бланк «Rx: Graphify» → пробковая доска, булавки-файлы, **красная нитка** между ними (граф знаний) |
| 7 | Таблетка вторая — Понитейл. \| Клод пишет как самый ленивый сеньор — \| только нужный код. \| В тестах авторов — на сорок пять процентов меньше выходных токенов. | баночка таблеток «PonyTail», лишние строки кода зачёркнуты маркером, «−45 %» + плашка источника |
| 8 | Меньше читать. \| Меньше писать. \| Дольше лимит. | три строки на рваных полосках, финальный кадр-постер |

**Проверка фактов (первоисточники):**
- «Весь разговор заново каждый ход» — так работает контекст модели; длинный чат и вложения тратят лимит быстрее.
  Формулируем качественно, без чужих цифр «двести токенов → десятки тысяч» (анекдотические).
- **Graphify** (Graphify-Labs, Apache-2.0, пакет `graphifyy`): один раз строит граф проекта локально (tree-sitter,
  без модели), дальше ассистент спрашивает граф (`graphify query/path/explain`), а не читает файлы. Цифры
  «в 71 раз меньше токенов» и «−80 %» — маркетинг/облачная версия без методики → **в ролик без цифры**, только механизм.
- **PonyTail** (DietrichGebert, MIT): промпт-правило «пиши только то, что нужно задаче». Бенчмарк авторов
  2026-10-07: Claude Code, Opus 5.5, 39 задач × 5 прогонов — **−45 % выходных токенов** (ДИ −54…−35), −26 % цены,
  −53 % кода. Сами авторы: экономия — побочный эффект, цель — меньше лишнего кода. Старое «−16 %» (v1.0.0) не брать.
  В кадре: «бенчмарк авторов, 39 задач, окт. 2026».

## 4. Перенос на наш движок

| Приём | Что есть | Пробел → как закрыть |
|---|---|---|
| Бумажный фон с зерном | кит `background: image` (фото «cover») | текстуру генерим в Kie один раз ($0.06) или рисуем кодом |
| Коллаж-иллюстрации | Kie `nano-banana-2` 2K + референс первой картинки держит стиль | промпт-«стиль-блок» один на все сцены (раздел 5) |
| Сборка «сзади вперёд» | `seedream/5-flash-layer-decomposition` → `media.image` `motion: parallax`, у слоя `at` (по слову), `sticker` — тень | камера: `zoom [1, 1.02]`, `pan` почти ноль |
| Маркер, круг, стрелка, красная нитка, рваная полоска с текстом | нет шаблона | бета: сцена `web.html` (HTML/CSS/SVG в Chromium — playwright и Chromium стоят); удачное — потом шаблон `vox.*` в движок |
| Движение «на двойках» 12 к/с | рендер 30 к/с, плавно | бета: в `web.html` — `steps()` / квантование времени; в движок — общий ключ «шаг времени» (правка движка: LESSONS, pytest, selftest) |
| Слово-маркер в субтитрах | `kit.kinetic`: слова влетают, `*акцент*` — плашкой цвета акцента (= жёлтый маркер) | субтитры кита `tiktok` на светлой бумаге проверить на stills; возможно, нужен стиль «маркер» |
| Звуки бумаги, штамп, скотч | `sfx.py`: pop, tick, whoosh, swish, thud, riser (синтез) | добавить paper / tape / stamp / marker (шум + огибающая, CC0) |
| Тихая музыка с ревербом | процедурный пэд студии | достаточно для беты |
| Шрифты | только Unbounded, Manrope, JetBrains Mono | нужны OFL с кириллицей: узкий жирный гротеск (Oswald), антиква (PT Serif / Source Serif 4), машинка (PT Mono); скачивание — с согласия |
| Голос | edge / piper бесплатно | бета: `ru-RU-DmitryNeural` или piper `ruslan` (ru), `en-US-AndrewMultilingualNeural` (en); ElevenLabs — после утверждения стиля |

**Решение для беты:** гибрид — предметы рисует Kie (одна фактура, коллаж), текст и пометки рисует код (`web.html`):
текст точный, правится без перегенерации, кириллица без ошибок модели.

## 5. Стиль-блок промпта Kie (черновик)
Один и тот же в каждой сцене, плюс референс — первая утверждённая картинка:
> hand-cut paper collage, editorial zine style, scissor-cut and torn paper edges, tape corners, halftone print dots,
> newspaper clipping textures, printed-paper cut-outs with real paper drop shadows, flat cream paper background,
> limited palette: ink black, highlighter yellow, marker red, kraft brown; high contrast, keep print grain;
> no text, no letters; vertical 9:16, subject centered.

Слова «3D», «CGI», «render» не писать (модели тянет в объём). Текст — не заказывать у модели.

## 7. Бюджет беты 40–45 с (Kie)
8 сцен: фактура бумаги $0.06 + 7 иллюстраций `nano-banana-2` 2K × $0.06 + ~5 раскладок на слои × $0.065 ≈ **$0.9**,
черновики `nano-banana` ~$0.2 → `budget_usd: 2`. Генерация — только после сметы `images` и «да».

## 8. Чего не делаем
- Не называем студию и ролик «Vox», не берём логотип, шрифты, точный жёлтый и футаж Vox — копируем жанр, а не бренд.
- Не делаем гладкую CGI-анимацию, неон и градиенты — это убивает «бумагу».
- Не заказываем текст у модели картинок.
- Не ставим непроверенные цифры (Graphify «71×», «−80 %»).

## 9. Порядок после согласования
1. Ответы: язык ролика, площадки, имя студии (раздел «Открытые вопросы»).
2. `new-studio` → `brand.yaml` по разделу 6, шрифты OFL, фактура бумаги.
3. **Три стоп-кадра стиля** (крючок, доска Graphify, PonyTail): Kie + `web.html` → показать → «да» (~$0.3).
4. Бета 40–45 с: `voice` (edge/piper) → `stills` → рендер в фоне → `qa`.
5. После утверждения: голос ElevenLabs; в движок — шаг времени 12 к/с, шаблоны пометок `vox.*`, звуки бумаги.

## Референс 2 — коллаж «Global Icon / Global Impact» (пользователь, 2026-11-09)
Пользователь принёс мастер-промпт «VOX-style editorial documentary image prompt generator» и 8 кадров его выхода.
Стиль студии сдвинут к нему; адаптация под наш конвейер — `studios/paper-explained/brand/PROMPTS.md`.
- **Слои кадра:** бумага → геометрия (большой терракотовый круг с растром, тонкие концентрические кольца, линии,
  кресты сетки, бежевые точки) → **огромный узкий заголовок 1–4 слова поперёк круга** → главный предмет —
  **ч/б полутоновая вырезка с белой кромкой**, перекрывает заголовок → 2–5 вспомогательных элементов → тени.
- **Палитра пипеткой:** бумага `#F6F0E2`, краска `#141210`, круг `#C46557`, синий `#5B7684`, тёмно-синий `#30353C`,
  беж `#DCCDB0`, редкий жёлтый `#E0C377`. Ярко-жёлтый маркер и ярко-красный из первой версии — убраны.
- **Отличия от исходного промпта:** заголовок и цифры — кодом (кириллица, правка без перегенерации); модель рисует
  только предмет на светло-сером (под `rembg`); логотипов брендов нет; вертикаль 9:16 — заголовок поперёк кадра,
  подписи ниже картинки, низ кадра — под интерфейс площадки.
- **Сейчас:** предметы — SVG-заглушки кодом (сеть машины режет файлы Kie). Когда скачивание заработает:
  `images` по промптам из `script/ch01.yaml` → `assets/images/<ключ>.cut.png`, и в телах сцен (`assets/src/sNN.body.html`)
  заглушку `<svg>` внутри `.sticker` заменить на `<img>` вырезки (подстановку в `build.py` сделать с первой картинкой).
