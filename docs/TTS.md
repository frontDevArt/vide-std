# Озвучка: бэкенды

Выбирается в `project.yaml → tts.backend`. Тайминги, субтитры и микс от бэкенда не зависят.
`python -m studio doctor` честно проверяет каждый бэкенд реальным синтезом.

| Бэкенд | Качество | Офлайн | Установка | Статус в студии |
|---|---|---|---|---|
| `rhvoice` | хорошее, «дикторское» | да | `bash tools/setup_rhvoice.sh` (сборка ~5–10 мин, один раз) | проверен end-to-end |
| `edge` | очень естественное (нейросеть Microsoft) | нет, нужен интернет | `pip install edge-tts` | код готов, в облачной песочнице не проверялся (сеть закрыта) |
| `elevenlabs` | лучшее, голос канала | нет, платно | ключ и голос в `.env` (см. ниже) | проверен 2026-10-21 (style-test: синтез, таймкоды слов, караоке, QA ✅); голос ~3 dB громче edge → `music.level_db` ≈ −14 |
| `piper` | естественное, нейросеть | да | бинарник piper + модель `.onnx` в `tools/piper-voices/` | код готов, не проверялся |
| `fake` | тон вместо речи | да | ничего (без ffmpeg) | **только тесты и черновики**: детерминированный, байт в байт на любой ОС; слово — по слогам (`textutil.weight`), паузы на `, : . ! ?` и на `|`, таймкоды слов в `.words.json`. `voice: auto` → `fake` |

Язык ролика — `language` в `project.yaml` (ru по умолчанию). При `tts.voice: auto` голос берётся из профиля
языка в `studio/lang.py` (там же фраза проверки, ориентир слов/мин и надписи шаблонов). Новый язык = запись в `LANGS`.

Голоса (ru):
- rhvoice: `aleksandr-hq` (мужской, спокойный). Другие: `VOICES="aleksandr-hq elena" KEEP_BUILD=1 bash tools/setup_rhvoice.sh`
  (при уже установленном — удалить `tools/rhvoice` и запустить снова).
- edge: `ru-RU-DmitryNeural` (мужской), `ru-RU-SvetlanaNeural` (женский).
- piper: `ru_RU-dmitri-medium`, `ru_RU-denis-medium`, `ru_RU-ruslan-medium` (файлы `<имя>.onnx` + `.onnx.json`).

Голоса (en):
- rhvoice: `slt` (женский), `bdl`, `alan` — сборка: `VOICES="aleksandr-hq slt" LANGUAGES="Russian English" bash tools/setup_rhvoice.sh`.
- edge: `en-US-GuyNeural`, `en-US-AriaNeural`, `en-GB-RyanNeural`.
- piper: `en_US-lessac-medium`, `en_US-ryan-medium`.

Английский путь пока не проверялся end-to-end: голоса по умолчанию и `wpm: 155` — оценка, уточнить на первом ролике.
`wpm` языка — только ориентир до первой озвучки: `voice` меряет реальный темп и кладёт его в
`build/voice_calibration.json` (`studio/calibration.py`), `validate` берёт замер, пока не сменились язык, бэкенд и голос.

Темп `rate` — проценты: 100 = норма бэкенда. Для edge переводится в `--rate=+N%`, для piper — в `length_scale`.

Если бэкенд недоступен — студия падает с понятной ошибкой на фазе voice. **Никогда не заменять
озвучку молча субтитрами** — сообщить пользователю и предложить вариант установки.

Произношение: если слово звучит неверно — перепишите фонетически или синонимом в `lines`
(субтитры можно оставить правильными, сделав для этой сцены отдельный шаблонный текст).
Латиницу и аббревиатуры `validate` подсвечивает.

## ElevenLabs (голос канала Notes From The Mind)
1. `.env` в корне студии (он в `.gitignore`, образец — `.env.example`):
   `ELEVENLABS_API_KEY=…`, `ELEVENLABS_VOICE_ID=…` (ID голоса из elevenlabs.io → Voices), опц. `ELEVENLABS_MODEL_ID`.
2. `project.yaml`: `tts: {backend: elevenlabs, voice: auto, rate: 100}` — `voice: auto` берёт `ELEVENLABS_VOICE_ID`.
   Темп — **только числом** (подбор `auto` синтезировал бы текст несколько раз — это деньги). `rate/100` → `voice_settings.speed`,
   ограничено 0,7–1,2. Необязательно: `model`, `stability`, `similarity_boost`, `style`, `use_speaker_boost`, `context` — входят в ключ кэша.
3. `python -m studio voice <проект>` сначала печатает, сколько символов уйдёт в синтез (кэш не считается), и **не синтезирует**
   без `--yes`. `doctor`/`probe` проверяют ключ и голос бесплатными запросами (`/v1/user`, `/v1/voices/{id}`):
   `doctor` пишет имя голоса, тариф и остаток символов; ключа нет — ⬜, ключ неверный/голоса нет — ❌. Ключ не печатается.
4. Эндпоинт `POST /v1/text-to-speech/{voice_id}/with-timestamps` → mp3 + времена символов → слова
   (`build/tts/<hash>.words.json`). 401/403/429 — понятная ошибка без ретраев.

### Сквозная интонация: `previous_text` / `next_text`
Каждая строка синтезируется отдельно, но в запрос уходят тексты соседних строк **в пределах главы** (через границы
сцен): модель слышит, что было до и что будет после, и не начинает каждую фразу как «первую». Синтезируется и
тарифицируется только `text`; контекст в оценку символов `voice` не входит (сверить с балансом на первом прогоне).
- Соседи входят в ключ кэша: правка строки пересинтезирует её **и двух соседей** (`voice` покажет число строк и символов).
- Граница главы контекст рвёт: правка `ch02` не трогает готовую `ch01`.
- Выключить: `tts: {context: false}` (например, если модель отвечает 400 на `previous_text`).
- Включение (2026-10-21) сменило ключи кэша: строки старых проектов ElevenLabs при следующем `voice --yes`
  синтезируются заново (style-test — 5 строк, ≈ 196 символов).

### Акцент на сцене или строке: `voice:`
Переопределяет настройки голоса поверх `project.yaml → tts` (только `elevenlabs`; другие бэкенды — предупреждение
`validate`, игнорируется). Ключи: `stability`, `similarity_boost`, `style` (0–1), `use_speaker_boost`, `speed`
(0,7–1,2, не быстрее `rate_range[1]/100` — речь не ускоряем), `model` (эксперимент). Входит в ключ кэша.
```yaml
  - id: s07
    voice: {style: 0.3}                 # на все строки сцены
    lines:
      - "So what did the data show?"
      - {text: "This one is false.", voice: {style: 0.4, stability: 0.35, speed: 0.95}}   # поверх сцены
```
Ниже `stability` и выше `style` — живее и эмоциональнее, но нестабильнее. **Правило канала: 1–2 акцента на ролик**
(крючок в начале, вердикт); спокойный рассказчик — часть тона (`channel/POSITIONING.md` §14). Больше двух — `validate` ⚠️.

### `eleven_v3` и теги эмоций — только эксперимент
Теги `[whispers]`, `[sighs]`, `[excited]`, `[pause]` понимает только `eleven_v3`. Риски: ниже стабильность, тембр
«плавает» от строки к строке; поддержку `with-timestamps` и `previous_text` в v3 сверить на реальном запросе —
без таймкодов отвалятся караоке и триггеры `lab_*`. Проба на одной строке: `voice: {model: eleven_v3}` у строки
style-test (теги `[a-z …]` в субтитры не попадают; без v3 — ⚠️ `validate`: тег прочитался бы вслух), `validate`, `voice --yes`, сравнить на слух
и в `stills`. Если 400 из-за контекста — `tts.context: false`. Каналу v3 по умолчанию не включать.

### Паузы
`<break time="0.6s"/>` не используем: разбор таймкодов его не знает. Пауза = новая строка (`pauses` в `project.yaml`)
или `|` для бита.

## Таймкоды слов
Нужны для слов-триггеров шаблонов `lab_*` и караоке-субтитров. ElevenLabs — из ответа API, edge — события WordBoundary
(Python API edge-tts), piper/rhvoice — оценка по слогам внутри битов. Времена сдвигаются на срезанную в начале тишину.
В `timeline.json` у каждой сцены — `words: [{w, t0, t1, line}]`.

> edge: синтез строки ограничен 90 с (`tts.EDGE_TIMEOUT`), при молчании сервиса — один повтор, затем честная ошибка `TTSUnavailable`.
