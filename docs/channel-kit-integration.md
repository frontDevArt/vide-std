# Интеграция channel-kit

Источник: `channel-kit.zip` → распакован в `.channel-kit-incoming/` (временно, удаляется в фазе 6).
Инструкция комплекта: `.channel-kit-incoming/ADAPT.md`. Дата разведки: 2026-10-21.

## 1. Разведка

### Комплект (что внутри)
| Файл | Суть |
|---|---|

| `channel/STYLE.md` | стайл-гайд анимации: палитра, шрифты, фон «лаборатория», сетка, 6 шаблонов композиции, движение (кривые, тайминги в кадрах), фирменные элементы, звук, синхронизация по словам, Shorts, чек-лист |
| `channel/style-demo.html` | эталон движения: 15 с, 1920×1080, кадр = функция от `t` (миф «21 день» → 66, MYTH) + синтез SFX в WebAudio |

### Проект (как устроен на самом деле)
| Что | Факт |
|---|---|
| Движок рендера | **свой Python: PIL + numpy → кадры в `ffmpeg` по pipe** (`studio/render.py`). Не HTML, не Remotion. Сцена = класс-шаблон с `setup()` (дорогое, один раз) и `draw(img, t, T)` (композиция спрайтов) |
| Шаблоны сцен | `studio/templates.py` (`@template(...)`, реестр `REGISTRY`) + свои в `projects/<slug>/templates/*.py`. У psy-day-80 уже есть `day_stop`, `day_fact`, `day_myth` (часы дня, плашка мифа) |
| Пресеты стиля | `gfx.PALETTES` — только цвета: `neon`, `calm`. Выбор: `project.yaml → style.palette`. Фон один (`gfx.Background`: градиент + зерно + плавающие пятна) |
| Шрифты | `style.font` → поиск через `fc-match`. **На Windows `fc-match` нет** → сейчас падает на `C:/Windows/Fonts/arialbd.ttf` (или `STUDIO_FONT_<ВЕС>`). Manrope/Unbounded/JetBrains Mono не установлены |
| Easing | `eo` (cubic out), `eio`, `eob` (back), `ei`. Нет expo-out, нет пружины из STYLE |
| Синхронизация | **биты `|`** в `lines`: граница = оценка по слогам → притяжение к реальной паузе в WAV. Таймкодов слов нет |
| Склейка | глобальное время `T` + `state_in` между сценами; сцены → `-c copy` → главы → финал; один микс на весь ролик |
| TTS | `rhvoice`, `edge` (edge-tts 7.3.1 установлен, работает), `piper` (модели ru в `tools/piper-voices/`). **ElevenLabs нет** — запланирован в `docs/ROADMAP.md` R5a, выравнивание слов — R9 |
| Звук | `studio/audio.py`: голос по таймлайну, процедурная музыка-петля, sidechain, LUFS (по умолчанию −16). **SFX нет совсем** |
| Субтитры | плашка внизу, нарезка по битам (`studio/subs.py`) |
| Бриф | `briefs/_TEMPLATE.md`, разделы 1–11 (1 Тема, 2 Язык/длительность/формат, 3 Зритель, 4 Стиль, 5 Голос и звук, 6 Структура, 7 Содержание, 8 Произношение, 9 Начало/конец, 10 Призывы, 11 Прочее) |
| `/new-video` | читает бриф целиком → фазы `docs/PHASES.md`: project.yaml → outline.md → `script/chNN.yaml` → voice → stills → render → assemble → qa. Раскадровка = выбор `template` + `params` в YAML сцены |
| Окружение | Windows 11, Git Bash, Python 3.14, ffmpeg 8.1, `claude` = `/c/nvm4w/nodejs/claude`. Нужен `PYTHONUTF8=1` |
| Git | ветка `master`, 1 коммит; **в рабочей копии 21 незакоммиченный файл + неотслеживаемые `briefs/`, `projects/psy-day-80/`, `studio/lang.py`** |

### Расхождения с предположениями комплекта
1. Движок не браузерный → `style-demo.html` переносится принципами, а не кодом (ADAPT 4.6, вторая ветка).
2. «Пресет» в проекте = только палитра. Для `lab` нужно расширить: фон, шрифты по ролям, радиусы, кривые.
3. Синхронизация по **словам** (STYLE §11) отсутствует — есть биты. Нужны таймкоды слов в `timeline.json`.
4. `POSITIONING.md §13` говорит «пресет `calm`», а `STYLE.md` описывает новый стиль → противоречие, правим §13 на `lab`.
5. `topics-log.md`: psy-day-80 записан как англоязычный Everyday Brain, а реальный проект psy-day-80 — **на русском**. Мифы из него помечены `mentioned` — это ок, но строку про сам ролик стоит уточнить.
6. В брифе нет полей: рубрика, вердикт, шаблоны композиции по сценам, список источников для описания. Голоса ElevenLabs в списке нет. Язык по умолчанию — ru.
7. Комплект пишет в `research/radar/` и `logs/` — таких папок нет; `.env` нет в `.gitignore`.
8. Конфликтов имён команд нет: `topic-radar.md`, `topic-to-brief.md` в `.claude/commands/` отсутствуют.
9. Громкость: проект −16 LUFS, STYLE требует −14. Музыка в STYLE −24…−28 dB под голосом — укладывается в QA-окно 14–28 LU.

### Пробелы / риски
- PIL не умеет дешёвый `backdrop-filter` и размытие на каждый кадр → стекло карточек = заранее отрисованная полупрозрачная подложка; размытие 8→0 на появлении — из 3–4 заранее размытых копий спрайта (кэш).
- Дрейф камеры 100→103 % = масштаб всего слоя контента каждый кадр → рендер медленнее (оценка +30–50 %). Замерю на тесте.
- Шрифты нужно скачать один раз (OFL, Google Fonts/GitHub). Если сеть/прокси даст 403 — сообщу, не обхожу.
- Без ключа ElevenLabs реальный вызов не проверить.

### Фаза 4 — стиль `lab` в движке (главное)
- `studio/style.py` (новый): пресеты как словари токенов (`neon`, `calm` — как были; `lab` — палитра STYLE §2, шрифты по ролям, радиусы 18/14, сетка 12×24, safe 96). `gfx.PALETTES` остаётся совместимым.
- Шрифты: `assets/fonts/` (Manrope, Unbounded, JetBrains Mono + `OFL.txt`), `gfx.font(size, weight, role=)` берёт файл из пресета — без сети при рендере. Заодно чинит Windows-фолбэк на Arial.
- `gfx.LabBackground`: две дышащие подсветки, сетка 48 px в нижних 40 % с маской, 34 пылинки, параллакс 0,5× — функция глобального `T` (бесшовно).
- `studio/motion.py`: `ease_out_expo`, `ease_in_out`, `ease_in`, `spring`, `appear()`, `stagger()`, `draw_line()` + бегущие точки, `count()`, `focus()`, `exit()`, idle-покачивание, дрейф камеры — тайминги в кадрах @30.
- `studio/lab.py`: фирменные элементы (штамп вердикта, карточка исследования с силой доказательств, «Миф → Реальность», толпа = выборке, карточка главы, часы дня, «Нейрон») + 6 шаблонов `lab_hero_stack`, `lab_flow`, `lab_versus`, `lab_crowd`, `lab_diagram`, `lab_full_number`, `lab_chapter`, `lab_verdict`. Морфинг между сценами — через `state` (как требует SCENE_SPEC).
- Слово-триггер: в `params` можно писать `at_word: "sixty-six"` → старт за 4 кадра до слова; без таймкодов — откат на биты.
- `/new-video` + `docs/PHASES.md` фаза 3 + `docs/SCENE_SPEC.md`: для `lab` — шаблон на сцену, слово-триггер на элемент, разрыв ритма каждые 20–30 с, чек-лист STYLE §13.

### Фаза 5 — голос и звук
- `_elevenlabs` в `tts.py` (stdlib, ключ из `ELEVENLABS_API_KEY`, эндпоинт `/with-timestamps` → символы → слова, сохраняются `build/tts/<hash>.words.json`), оценка символов и подтверждение перед платным синтезом. Параметры API сверю по актуальной документации.
- Запасные таймкоды: `edge` — WordBoundary (бесплатно, проверю на 7.3.1); `piper`/`rhvoice` — оценка по длине слов внутри битов.
- `studio/sfx.py`: pop, tick, whoosh, thud, riser, swish — синтез numpy (свои, `assets/sfx/LICENSES.md`: «сгенерировано кодом, CC0»). Шаблоны отдают события, `audio.mix` кладёт их на −30 dB к голосу. Для `lab`-проектов `loudness: -14`.
