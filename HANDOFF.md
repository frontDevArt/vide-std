## 1. Подготовка домашней машины (делает человек или агент)
Windows: перед командами студии — `PYTHONUTF8=1` (без него падает на кириллице, piper виснет).

1. Несохранённая работа: `git status`. Есть изменения — закоммитить или `git stash`, потом дальше.
2. Ветки:
   ```bash
   git fetch origin
   git checkout master
   git pull --ff-only
   git checkout stage-G
   git pull --ff-only
   ```
3. Окружение:
   ```bash
   pip install -r requirements.txt
   python -m studio doctor
   ```
   В выводе должна быть строка ✅ `TTS [ru] piper`. Голоса piper в git не хранятся (`tools/piper-voices/`):
   нет `ru_RU-ruslan-medium` — поставить по `docs/TTS.md`. Нет никакого рабочего голоса — сказать пользователю
   и остановиться (железное правило).
4. Чистка кэшей всех роликов (на этой машине их много, в том числе часовой `twelve-myths`). Сначала отчёт:
   ```bash
   python -m studio --studio notes-from-the-mind clean --older-than 1h --dry-run
   python -m studio --studio default clean --older-than 1h --dry-run
   ```
   Показать отчёт пользователю, затем те же команды без `--dry-run`. Что важно:
   - платную озвучку (ElevenLabs) `clean` **не удаляет никогда** — перерендер потом бесплатный (у `twelve-myths`
     ~50 тыс. символов озвучки, на тарифе столько нет — её терять нельзя);
   - удаляются рендер сцен, микс и финалы `build/final/`; оставить MP4 — `--keep-final` (спросить пользователя);
     версии сдачи `output/<slug>/vN/` не трогаются;
   - `--studio yereva` чистить не нужно: там только демо.
5. Демо Yereva в git не попадает (`*-demo` в `.gitignore`) — собрать заново:
   ```bash
   python -m studio demo yereva-style
   ```
   Результат: `studios/yereva/projects/yereva-style-demo/build/final/yereva-style-demo.mp4`, QA — все ✅.
6. Логотип перегенерировать нужно только при правке: `pip install fonttools`, затем
   `python studios/yereva/brand/logo/make_logo.py` (готовые SVG и PNG уже в git, `out/`).

## 2. Что сделано по замечаниям и что открыто
Замечания пользователя к первому демо и что с ними сделали (2026-10-28):
- «фон очень мрачный» → тёмно-синий (см. выше);
- «начало слабоватое» → начало на карте: `kit.map` с булавками конкурентов (Арабкир, Кентрон, Давташен) по словам
  озвучки, `pin_scale: 1.7`, дальше удар «Вас среди них *нет.*»;
- «мало motion» → **правка движка** (ветка `stage-G`, тесты `tests/test_kinetic.py`, справочник в `SCENE_SPEC.md`):
  - новый шаблон `kit.kinetic` — кинетический текст: слова влетают под речь, акцент — ударом и плашкой цвета
    акцента, страницы меняются; субтитров у такой сцены нет (текст в кадре и есть речь), в `.srt` остаются;
  - ключ бренд-кита `motion: {transition: wipe, bg: 2.5}` (`docs/BRAND.md`) — шторка между сценами
    (`render.draw_wipe`, 0,2 с с каждой стороны склейки) и пятна фона в 2,5 раза живее; без ключа старые киты и
    кэш рендера прежние, golden не менялся (selftest ✅);
  - `kit.map`: параметр `pin_scale` (крупные булавки для вертикали).
- Демо теперь 16 с, 5 сцен: карта → «вас нет» → кинетический текст → логотип → призыв.

**Открыто — шрифт.** «Буквы не нравятся» (сейчас Manrope). Пользователю показан лист пяти шрифтов на синем:
Manrope, Unbounded, Montserrat, Onest, Geologica (последние три — OFL с github.com/google/fonts, скачивались во
временную папку, в репозитории их нет). Когда выберет: файл и `OFL.txt` → `studios/yereva/brand/fonts/`,
в `brand.yaml` `fonts.head` и `fonts.num` на него (`license: OFL-1.1 (brand/fonts/OFL-….txt)`), пересобрать демо.
Совет Claude был — Montserrat (геометрия как у надписи логотипа) или Unbounded (самый «рилсовый», но широкий).
Порядок проверки любых правок: `python -m studio demo yereva-style --no-render` → `voice yereva-style-demo` →
`stills yereva-style-demo` → **посмотреть PNG** → `demo yereva-style` → показать MP4 и ждать «да».
Цифр в демо нет и не будет: своих кейсов у агентства ещё нет, выдуманные запрещены (`studios/yereva/CLAUDE.md`).
